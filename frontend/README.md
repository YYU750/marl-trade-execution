# MARL 冻结策略回放前端

用 React、TypeScript、Vite、CSS Modules 和 ECharts 实现。界面以蓝色渐变、半透明卡片和联动时间轴为主。需要 Node.js 20.19+ 或 22.12+。

## 本地运行

在本目录执行：

```powershell
npm install
npm run dev
```

打开终端打印的本地地址。生产构建执行 `npm run build`，生成静态目录 `dist/`，可用 `npm run preview` 本地预览。

## 演示

- 总览在第 18 步打开。播放、暂停、切换前后步、拖动时间轴或调整倍速都会联动 A/B 决策与市场反馈。
- 点任一基金的「决策详情」检查状态、各档 Q 值、访问次数与期限可行性。市场页展示价格转移、冲击和当步含费成本。回合总结展示全局成本、完成率、动作分布与复算结果。
- 「导入回放」可读取本地 `schema_version: "1.0"` 的冻结回放 JSON。「恢复样例」切回默认回放。

## 数据接入

内置样例 `public/demo_frozen_episode.json` 由现有导出脚本生成，取自 `wuxinhan-1@96d4a6b` 的第 500 回合检查点，情景为正常波动，种子 20261105。样例中的检查点路径已改为仓库相对路径。

默认数据源可以替换该 JSON，也可在 `.env.local` 设置 `VITE_REPLAY_URL` 指向兼容的 JSON 地址。浏览器跨域读取时，数据服务需允许对应来源。接口结构变化集中在 `src/replay.ts` 的类型与校验函数中。

页面只展示冻结回放，Q 值来自检查点。永久冲击通过下一步中间价传导。总实施缺口与完成率对应指定的单局模拟。
