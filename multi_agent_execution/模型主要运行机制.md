# A/B 双边同步学习模型的主要运行机制

> **历史版本说明：** 本文记录的是限价单版本之前的“提交即成交”模型。当前主模型已加入队列和部分成交，并默认由 Agent 自主决定全部盘中动作，仅在截止步由环境按显式冲击成本兜底成交余量；旧版 `c` 可选启用盘中加急。请以 [限价单多智能体模型机制说明.md](限价单多智能体模型机制说明.md) 为准；本文机制和旧结果不得与新限价单模型结果直接合并。

## 1. 模型定位

当前主模型是 A、B 双边同步学习的多智能体交易执行仿真。两家机构各自持有买入母单，同时面对时间限制、交易成本和对手订单流。A、B 都使用表格型 Q-learning，双方当前动作共同改变成交成本和后续市场价格。训练后，系统冻结策略检查点并进行交叉对局，分析策略互动、训练稳定性和候选集最佳反应。

模型不调用生成式模型服务，不连接真实行情、账户或下单接口。价格、冲击和状态转移是教学假设，模拟结果不等于真实市场结论。

课堂资料规定收盘前 30 分钟执行，没有指定决策步长。项目将其离散为每 30 秒一步，共 60 步；该步长是建模选择。

## 2. 一回合如何运行

每回合开始时，A、B 各有 100,000 股待买订单，中间价为 100。每个 30 秒时间步按以下顺序运行：

| 步骤 | 运行内容 |
|---|---|
| 1. 共享观察 | 市场给出当前时间、中间价等共同交易前状态；每个 Agent 同时读取自己的剩余订单和对手上一期成交量 |
| 2. 同步选动作 | A、B 分别读取自己的 Q 表，按各自可行动作选择本步下单量；任何一方都看不到对方本步的新动作 |
| 3. 统一撮合 | 环境将 A、B 子单合并计算，更新成交价、手续费、订单剩余量和下一步中间价 |
| 4. 双边反馈 | 环境根据各自成交、剩余库存和终端状态计算奖励，分别更新 A、B 的 Q 表 |
| 5. 记录运行 | 保存动作、奖励、成本、完成率及训练诊断 |

A、B 先完成本步动作选择，市场再处理共同订单流。Q 表更新只影响之后的决策，不会改写本步已经选定的动作。双方策略在训练中都持续变化，因此任一 Agent 面对的对手策略和状态转移分布也会变化，学习过程具有非平稳性。

## 3. Agent、状态与动作

### Agent 职责

| 对象 | 机制 |
|---|---|
| Agent A | 以自身库存、时间、价格和 B 上一步成交量为观察，输出买入子单并更新自己的 Q 表 |
| Agent B | 以自身库存、时间、价格和 A 上一步成交量为观察，使用独立 Q 表同步学习 |
| 市场环境 | 统一计算成交、费用、冲击和下一时点价格，不作为学习型 Agent |
| 评估器 | 冻结训练检查点，组合测试 A/B 策略并计算成本、稳定性和候选集响应 |

### 状态

每个 Agent 使用紧凑离散状态：

- 执行时间阶段：每 10 个 30 秒时间步合并为一档，共 6 档；
- 订单执行进度：剩余订单量除以剩余时间内均匀执行所需量，分为低于 0.75、0.75–0.90、0.90–1.05、1.05–1.20、至少 1.20 五档；
- 中间价相对初始价偏离：以 −6、−3、−1、1、3、6bp 为分界，共 7 档；
- 对手上一期成交量相对 TWAP 基准份额：低于 0.25 份、0.25–1.25 份、至少 1.25 份。

将精确时间合并为阶段、用执行速度描述库存进度，可以让相邻时间和类似进度的样本共用 Q 值。波动率用于生成价格扰动及压力测试，但不直接作为 Q 状态。A 观察 B 上一期成交量，B 观察 A 上一期成交量；系统没有使用身份识别或未来动作预测。

### 动作与完成约束

TWAP 基准份额为母单除以步数，即约 1,666.67 股。双方动作集合相同：

| 动作 | TWAP 倍数 | 单步数量约值 |
|---|---:|---:|
| 等待 | 0 | 0 股 |
| 半份 | 0.5 | 833 股 |
| 基准份 | 1.0 | 1,667 股 |
| 较大份额 | 1.5 | 2,500 股 |
| 最大份额 | 2.0 | 3,333 股 |

若本步之后剩余时间内即使每步都买入最大份额仍无法完成订单，系统会提高当前允许的最小动作：

```text
本步最低可行量 = max(0, 当前剩余订单 − 后续剩余步数 × 2 × TWAP 基准份额)
```

此约束对 A、B 一致，避免策略通过少成交来获得表面上较低的成本。

## 4. 市场成交、冲击与奖励

### 订单冲击与成交价

当前市场参数包括半价差 2bp、临时冲击系数 0.35bp/份、永久冲击系数 0.20bp/份。设 `qA` 和 `qB` 为双方子单、`λB` 为对手影响系数，则：

```text
合并冲击量 = qA + λB × qB
临时冲击 = 0.35bp × 步长分钟数 × 合并冲击量 / TWAP 基准份额
毛成交价 = 当前中间价 × [1 + (半价差 + 临时冲击) / 10,000]
手续费/股 = 当前中间价 × 单边费率 / 10,000
含费成交价 = 毛成交价 + 手续费/股
```

双方子单共同进入临时冲击，所以同一回合的订单流会影响两边成交成本。永久冲击影响下一时点中间价：

```text
永久冲击 = 0.20bp × 步长分钟数 × 合并冲击量 / TWAP 基准份额
下一时点中间价 = 当前中间价 × [1 + (外生随机扰动 + 永久冲击) / 10,000]
```

正常波动率是每分钟标准差 2.5bp；两倍波动测试将其乘以 2。半价差和手续费显式计入成本。

### 奖励和结果成本

每个 Agent 的逐步训练奖励与已成交部分的实施缺口对齐：

```text
本步奖励 = −本步成交量 / 母单 × 本步含费实施缺口
终局惩罚 = −未完成订单比例 × 1,000bp
```

当前主模型不再在每一步额外扣除库存风险项，避免学习目标与报告成本不一致。对全额完成的订单，逐步奖励就是成交部分的含费实施缺口；未完成订单仍接受终局惩罚。结果成本拆为成交部分毛执行缺口、显式手续费和未成交订单机会成本：

```text
总实施缺口 = 成交部分毛执行缺口 + 手续费成本 + 未成交机会成本
```

因此报告同时列出成本、完成率和未完成股数；不能只凭累计奖励或 Q 值判断策略经济效果。

## 5. 双边学习和检查点

A、B 各自维护独立 Q 表。训练使用 epsilon-greedy，探索率从 0.35 随回合线性下降到 0.05；学习率 α 为 0.15，折扣因子 γ 为 0.98。一次更新为：

```text
Q(s,a) ← Q(s,a) + α × [r + γ × max Q(s',a') − Q(s,a)]
```

下一状态只在已尝试且可行的动作中取最大 Q 值。如果尚无已尝试动作，则暂以 0 作为后续值。这样避免负成本奖励下，未尝试动作的零初值虚高并被误当成更好的选择。A 与 B 先分别选择本步动作，环境完成共同撮合后，再把各自奖励反馈到各自 Q 表。

默认每个训练种子训练 500 回合，检查点为 0、100、200、300、400、500。第 0 回合作为未训练策略参考。训练场景为正常波动；训练期间 A、B 始终互为学习型对手。

## 6. 冻结交叉评估、稳定性与最佳反应

训练完成后，所有检查点 Q 表冻结。每个训练运行内，将 6 个 A 检查点与 6 个 B 检查点两两组合；每种组合在正常波动和两倍波动下各使用 30 个配对随机种子。默认共：

```text
5 个训练种子 × 6 个 A 检查点 × 6 个 B 检查点
× 2 个波动场景 × 30 个评估种子 = 10,800 回合
```

交叉评估不继续更新策略。相同评估种子为不同策略组合提供相同外生价格冲击，策略带来的价格路径变化作为内生反馈保留。

稳定性诊断包括训练滚动奖励、训练滚动成本、跨种子成本差异、已访问状态数、Q 表状态数，以及 A/B 同检查点组合的对角线表现。若这些指标随检查点波动，或不同训练种子给出不同策略，不应声称收敛。

对固定的 B 检查点，A 的候选集最佳反应是当前训练保存的 A 检查点中成本最低者；对固定的 A 检查点，B 同理。候选集后悔值为当前检查点成本减去该有限集合内的最低成本。该计算不是全局最优搜索，也不单独证明纳什均衡。

## 8. 同环境规则策略配对比较与 Q-learning 改进

为直接比较规则策略和 Q-learning，新增 `run_matched_rule_q_comparison.py`。所有 A 策略都调用同一成交环境，以 TWAP、动态规则、旧单边 Q、当前双边自博弈学到的 A 策略，以及成本对齐的紧凑状态 Q 候选进行比较。A 面对相同的固定 B 对手类型；同一个 B 对手、场景和评估编号共用相同外生随机冲击、手续费、母单和期限。每类 B 对手在正常与两倍波动下各用 50 个配对随机种子。

| A 策略 | 正常波动平均成本 | 两倍波动平均成本 |
|---|---:|---:|
| 固定 TWAP | 38.504bp | 39.120bp |
| 动态规则 | 38.453bp | 38.724bp |
| 当前双边自博弈 Q 的 A 策略 | 39.634bp | 40.388bp |
| 成本对齐的紧凑状态 Q 候选 | 39.236bp | 39.904bp |

平均值对五类 B 对手等权；配对成本差按 250 个“对手 × 随机种子”格计算。当前双边自博弈 A 策略比动态规则高 1.180bp（近似 95% 区间 0.853–1.507），两倍波动高 1.664bp（0.976–2.352）。成本对齐的紧凑状态 Q 候选分别比动态规则高 0.782bp（0.519–1.046）和 1.180bp（0.660–1.700），但比当前自博弈 A 策略低 0.398bp（−0.542 至 −0.253）和 0.484bp（−0.788 至 −0.180）。

改进候选使用更紧凑的状态表示、让训练 TD 奖励与实施缺口一致，并屏蔽未尝试动作的零初值高估；它在固定规则对手混合中训练，不是双边同时学习主模型的替代版本。当前结果显示规则策略仍有更低成本，所以报告应保留这一结论。100% 完成率来自全额成交假设和截止时间可行性约束，不能作为策略优越性的证据。

### 进一步的 Q 改进检验

后续又实现阈值对齐双 Q：使用与动态规则相关的价格、订单进度和时间阶段，采用双 Q 表，并用独立训练轨迹的 Monte Carlo 回报初始化规则动作；训练覆盖五类固定 B 对手和两种波动。评估加入保守改进门槛，只有 Q 的动作价值超过规则先验且该动作有至少 25 次访问时，才执行偏离动作。

新留出种子下，动态规则成本为正常波动 38.364bp、两倍波动 35.802bp；规则先验双 Q 为 38.379bp、35.806bp。配对差为正常波动 +0.015bp（近似 95% 区间 +0.002 至 +0.027），两倍波动 +0.005bp（−0.019 至 +0.029）。因此 Q 已接近规则策略，但没有优于规则的证据。将训练增加到每个种子 30,000 回合后，5bp 门槛仍略高于规则；10bp 门槛几乎回到规则策略本身。

改进 Q 的训练和留出结果、不同偏离门槛的统计见 `outputs/q_algorithm_tuning.md`；原始逐局数据和运行清单在 `outputs/matched_rule_q_comparison/`、`outputs/q_improvement_validation_20261108/` 与 `outputs/q_improvement_long_20261110/`。规则先验帮助 Q 复现规则行为，不代表 Q 从零发现了更优策略。当前仿真结果不支持“Q-learning 稳定优于动态规则”的结论。

### 新测试种子的小范围复核

随机 B 每步仍随机选择 0.5 或 1.5 倍 TWAP，但新增与 A 一致的 2 倍最大子单完单下限；当剩余时段不足以完成母单时，随机动作提升到最低可行成交量。规则先验 Double Q、TWAP 和动态规则在固定新测试主种子 20261112 下配对比较，每类 B 对手和正常/两倍波动场景各 50 个种子；固定使用已选的 5 bp 门槛，不在测试集调参。

30 bp 手续费下，正常波动的 Q、动态规则和 TWAP 平均成本分别为 38.400、38.386、38.337 bp；Q 相对动态规则高 0.014 bp（近似 95% 区间 +0.002 至 +0.026）。两倍波动分别为 38.217、38.229、38.188 bp；Q 相对动态规则低 0.012 bp（−0.046 至 +0.021），区间包含 0。Q 与动态规则逐步动作一致率分别约 96.84% 和 97.27%。A、B 完成率均为 100%。本次只重训一个 Q 种子，区间不包括训练种子不确定性，因此结果只能说明新测试集上两种策略表现接近。

Q 表在测试期设为只读：未见状态只用零值临时读取，不加入表中；Q 值和动作访问计数评估前后哈希一致。折扣因子为 γ=0.98；Double Q 的非终止目标为 `r + γ × Q_evaluator(s', argmax Q_chosen(s', a))`，终止目标为 `r`，不进行终止自举。目标计算示例 `−2 + 0.98 × (−10) = −11.8` 已核对。完整输出（逐局成本、动作序列、各动作成交量、配对差、B 完成率和运行清单）见 `outputs/followup_validation_seed20261112/`；运行入口为 `run_followup_validation.py`。

## 两条研究路线的区别和结果口径

项目包含两条互补但不可混为一谈的实验路线。

**路线 A 是主研究。** A、B 各自维护 Q 表，同时训练并同步选择动作。每个训练回合双方订单流共同影响成交和下一时点价格；训练后冻结多个检查点，对 A、B 检查点作全组合交叉评估。比如 `(A@100, B@500)` 和 `(A@300, B@200)` 可以检验不同学习阶段的策略组合是否改变成本。该路线用于研究多智能体策略互动、训练稳定性和有限候选集最佳反应。

**路线 B 是算法扩展。** 单个规则引导 Double Q 学习者面对固定的 TWAP、动态规则或其他脚本对手，按配对随机种子比较成本、完成率和逐步动作一致率。它可以回答 Q-learning 相对规则策略是否有增量价值，但不是 A、B 同时学习的博弈证据。两类实验应在报告中分开写结果、表格和结论。

当前报告统一以路线 A 为主模型：30 分钟、每 30 秒一步（60 步）、A/B 各 100,000 股、γ=0.98、单边手续费 30 bp（0.3%）。每家机构按 100 元价格和 100,000 股计算母单金额为 1,000 万元，30 bp 手续费约为 30,000 元。历史材料中的“0.3 bp”若指 0.3 个基点，则金额是 300 元，和当前参数差 100 倍；在查清历史口径并按统一配置重跑前，旧结果不能直接与当前结果合并。若报告最终采用其他费率，应从同一环境重跑所有主比较。

步长从 60 秒调整到 30 秒时，代码按时间长度缩放临时/永久冲击，并按时间长度平方根缩放外生波动。旧版 30 步模型的价格分解和结果不应直接套用到 60 步模型。本文描述的旧模型通过截止时间可行性下界和提交即成交假设实现 100% 完成；当前默认模式由 Agent 自主决定盘中动作，再由终端兜底成交保证任务结清，并单独记录兜底股数与成本。两者的完单实现机制都属于环境设计，均不能当成策略优势，也不代表真实市场一定存在足够流动性。

可用 `export_self_play_trace.py` 从已保存的第 500 回合双边检查点导出完整同步学习样例。CSV 每步并列记录双方观察、同时动作、联合订单量、成交价、市场冲击、奖励和 TD/Q 更新。该额外演示回合使用检查点的临时副本，不计入主实验交叉评估，也不会修改原 Q 表。

## 适用边界

本模型是单资产、单向买入、批次撮合仿真，不包含真实历史行情校准、完整订单簿、队列优先级、隐藏流动性、真实部分成交或交易接口。双方目标和执行规则相同，结果不能概括现实市场全部的机构竞争机制。训练中的双边策略非平稳；检查点评估和多种子诊断用于观察该现象，但不会自动保证收敛。旧版单学习者/固定规则对手代码保存在 `run_standard_benchmark.py`，主模型和本文均以双边同步学习为准。
