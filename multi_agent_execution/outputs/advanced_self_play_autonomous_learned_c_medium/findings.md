# 双边同步 Q-learning：本轮运行记录

- 训练：5 个独立种子，每个 500 回合；每回合 60 个 30 秒时间步。
- 冻结交叉评估：每个训练运行 6 个检查点，30 个配对随机种子；单边手续费 30 bp。
- 训练在正常波动环境进行；训练检查点分别冻结后，在正常与 2 倍波动场景做交叉对局。
- 本结果属于路线 A（A/B 双边同步 Independent Q-learning）；路线 B 的规则引导 Double Q 对固定规则对手实验须单独报告。
- 当前单边费率为 30 bp（0.3%）；按初始价 100、每方母单 100,000 股估算，单家满额手续费约 30,000。
- 完成惩罚：每步对落后均匀进度的数量按 10 bp 系数惩罚；终局对未完成量或送入收盘兜底的数量按 1000 bp 系数惩罚。该项属于学习奖励，不计入经济交易成本。
- 完单配置：双边 Q-learning + 学习型 C 决策 + 终端完单兜底。
- 盘中策略：Q-learning Agent 与独立 C 决策头共同学习。每个时间步若落后线性进度，C 决策头结合精确时间、缺口、价格、挂单和对手近期成交状态，联合选择是否加急、IOC 报价上移 1/3/6 tick，以及本步额外提交当前进度缺口的 0/25/50/100%；42、51、57 步（约 20 分 30 秒、25 分钟、28 分钟）只是分析参照，Agent 可在任一落后时间点自行启动、等待和决定追赶幅度。普通撮合后，终端兜底仅处理剩余母单。
## A+B 市场参与率分层

- 本次训练和评估使用 **medium参与率档**；预设 A+B 计划参与率为 25%。两家各下单 100,000 股，合计计划量 200,000 股；按定义需要的背景成交量期望为 600,000 股/30 分钟，约 10,000 股/30 秒步。背景量由独立对数正态过程生成，变异系数参数 sigma=0.25，并排除 A、B 成交。
- 合成订单流与盘口深度相对 25% 中档按背景量线性缩放，活动倍数为 1.0000；临时/永久冲击及终端兜底冲击按背景量平方根反比调整，有效冲击倍数为 1.0000（基准 Config 冲击倍数 1）。此为可复现的教学情景映射，不是实证校准。
- 主实现份额按普通盘口撮合量计算：普通 A+B 成交量 ÷（普通 A+B 成交量 + 其他参与者背景成交量）；另单列含终端兜底的比例。终端兜底是合成收盘流动性，不纳入 Agent 普通市场成交份额。
- 背景成交量是独立生成的外生市场活动代理，不是由完整第三方订单逐笔撮合出来的背景交易量；因此表中实现参与率是模型内情景统计，不能当作现实市场实测份额。

| 波动情景 | A+B 普通撮合实现参与率均值 | 含兜底实现参与率均值 | 背景成交量均值 (股) | A+B 普通成交量均值 (股) |
|---|---:|---:|---:|---:|
| normal | 24.29% | 25.03% | 599,437 | 192,306 |
| high_volatility | 24.44% | 24.99% | 600,889 | 194,288 |

- 普通执行仍是教学用事件驱动限价单：成交量由队列、可见卖盘和随机订单流决定；IOC 只触达其限价范围内的卖盘；终端兜底使用显式合成深层流动性价格曲线，并单独记录强制成交股数。
- 本文件的数字仅是本次命令参数下的模拟结果，不自动代表收敛或现实市场效果。

## 解释边界

- A、B 在每步基于同一交易前快照同步决策，各自只能观察自身库存、上期对手成交量和自己的当前挂单；市场之后统一处理可成交限价单和卖方主动订单流。终端兜底数量不是 Agent 自主成交量。
- 动作 0 保留已有报价或等待；动作 1–3 分别挂深档买单、最佳买价和价差内报价，动作 4 提交价格上限为卖一价上方一档的可成交限价 IOC。被动订单可部分成交并保留，队列在 4 个时间步（2 分钟）后过期；IOC 未成交余量立即撤销。
- Q 状态包含时间阶段、执行进度、价格偏离、对手上期成交量、当前报价档位、挂单余量、队列前方数量和订单年龄。学习奖励按实际成交成本、每步进度缺口惩罚及终局残余惩罚计算；自主模式终局惩罚按收盘兜底前余量计算。纯 Q 模式下盘中实际动作等于 Agent 提出的动作；随机 C 模式下 Q 动作作为候选，最终执行动作可能经 C 抽样调整，Q 表按最终动作更新。下一状态只从已尝试动作中自举。训练中双方策略都变化，环境对单方而言仍是非平稳的。
- 买方被动成交由卖方主动订单流穿过队列触发；IOC 限价单按各自报价上限消耗合成卖盘。手续费只按实际成交名义金额计算。
- 检查点交叉对局把已保存的策略冻结后进行组合评估，避免评估过程继续改写 Q 表；配对种子共享外生价格冲击。
- 稳定性要结合多训练种子的滚动奖励、成本波动、状态覆盖与检查点交叉结果判断。单一训练曲线变平不足以证明收敛。
- 历史资料若使用 0.3 bp 或 30 个时间步，未按当前手续费和 60 步配置重跑前不得与本结果并表。
- 可用 export_self_play_trace.py 从保存的最终检查点生成一条额外的 A/B 同步动作、市场反馈和 Q 更新样例；说明性轨迹不进入本次交叉评估统计。
- 本次模式结果写入 outputs/advanced_self_play_autonomous_learned_c_medium；无兜底模式和硬完单模式的完成约束不同，不能仅按成本高低直接排序。规则策略配对比较仍由 run_matched_rule_q_comparison.py 单独生成，并须使用相同限价簿和完成约束重新评估。
- 该环境是未用真实行情校准的合成订单簿，不含完整撮合交易所规则、隐藏流动性或实盘接口；队列深度、订单流和收盘深层流动性兜底均为显式模拟假设。
