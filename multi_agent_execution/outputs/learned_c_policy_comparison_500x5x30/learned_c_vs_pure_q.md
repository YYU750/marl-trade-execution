# 学习型 C 训练 vs 纯 Q 基线：配对对照

- 两组都使用 5 个独立训练运行、每个 500 回合、相同基础随机种子、30 bp 单边手续费、相同进度/终局惩罚参数。
- 对每个训练运行及场景，取 A/B 都使用第 500 回合策略的最终检查点对局。两组使用相同评估种子，共每场景 150 个配对对局。
- 差值定义为学习型 C 训练 − 纯 Q 训练。负数表示平均兜底股数或成本降低。95% 区间是配对均值差的近似 t 区间。
- 这是两种训练方式的端到端比较，训练后的 Q 策略不同；要单独估计评估时 C 动作的影响，请同时查看同一学习型检查点的 C 覆盖消融报告。
