# 学习型方案 C、动态规则与固定 TWAP 对照结果

## 实验设置

- 每个市场情景使用 5 个独立训练种子 × 30 个配对种子；策略 A 的有效样本数为 150。
- 单边手续费：30 bp；母单：100,000 股；时间窗：30 分钟，每步 30 秒，共 60 步。
- 市场：同一个事件驱动合成限价订单簿，含部分成交、排队、挂单到期、IOC、双方交易冲击及终端兜底。每个配对单元对三种 A 策略和两个固定 B 对手复用同一组外生订单流、盘口深度和随机撮合顺序；交易行为导致的价格路径变化是模型内生结果。
- 学习型 C：使用第 1000 回合冻结的双边 Q-learning 检查点中 A 的常规 Q 表和独立 C-Q 决策头；测试时不更新参数。落后时 C-Q 从 no-C 或 12 种 IOC 报价/追赶量组合中选择；追赶量是在普通 IOC 子单上增加当前进度缺口的 0/25/50/100%。B 为固定规则策略或固定 TWAP。
- 动态规则：沿用 G1 的阈值（进度缺口、价格偏离和冲击条件）选择限价订单动作；当前 LOB 中报价未必成交，因此不使用旧全额成交环境的可行量下限。
- 固定 TWAP：每 30 秒提交 1 个 base slice 的 marketable-limit IOC，限价上限覆盖模拟的七档卖盘；若可见深度不足仍会部分成交并取消余量。策略固定等时间切片和每片数量，不根据盘中反馈调整。
- 三种方法统一使用 autonomous completion。100% 完成率由各方法共享的终端兜底保证，不代表盘中自主成交率为 100%；主要比较盘中自主成交股数、兜底股数和总实施成本。
- 成本为总实施缺口（含成交价格、手续费及兜底价格影响），单位 bp；越低越好。配对差异定义为左侧策略减基准，负值表示左侧成本更低或兜底更少。95% 区间采用配对样本均值的正态近似。

## 核心发现

1. 固定对手为动态规则时，学习型 C 相比动态规则在正常/高波动场景的成本分别低 6.31/6.27 bp；自主成交率分别高 41.39/43.39 个百分点，配对区间均未跨 0。
2. 固定对手为 TWAP 时，学习型 C 相比动态规则的成本分别低 6.66/6.18 bp，自主成交率分别高 57.35/58.08 个百分点。说明固定规则对手下的动态规则较容易落后，学习策略的优势更明显。
3. 学习型 C 没有稳定胜过固定 TWAP。固定 TWAP 的 A 成本在四个情景/对手单元都更低：相对学习型 C 分别低 1.08、1.06、0.91、0.78 bp（按正常/高波动、B=动态规则/TWAP 顺序）。TWAP 通过每步主动吃单减少残余，代价是承担买卖价差和手续费。
4. 学习型 C 的兜底占比在四个单元为 0.52%、0.34%、6.97%、6.28%；而固定 TWAP 对应为 0.00%、0.00%、0.43%、0.40%。这里的 100% 总完成由共享终端兜底保障。

## 结果解释

这项实验回答的是：在两类同一固定对手面前，冻结的学习型 C、固定阈值动态规则和固定 TWAP 在同一限价订单簿的成本及自主成交表现如何。它不证明真实市场收益，也不代表训练期在线适应；订单簿深度与订单流均为合成设定。

终端兜底让母单最终全额完成，但兜底量本身是核心结果之一。若某策略总成本低但兜底更多，需要同时考察自主成交量和兜底成本，不能只按总成本下结论。
