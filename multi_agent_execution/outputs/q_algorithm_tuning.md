# Q 算法改进与保留集结果

## 比较设置

动态规则、固定 TWAP 和各版 Q 策略使用同一市场模拟器、手续费、母单、时限、固定 B 对手类型及配对市场冲击。B 对手包括 TWAP、前置、后置、突发和随机策略；评估覆盖正常与两倍波动。每个对手与场景使用 50 个评估种子。训练种子与评估种子分开设置，最终评估种子没有用于训练或阈值选择。

改进版阈值对齐双 Q 把时间划分为 5 步阶段，状态边界对应动态规则使用的订单进度和价格阈值，并加入波动档和对手上一期成交量。两张 Q 表交替更新以降低最大化偏差。训练先用动态规则产生的训练轨迹，以 Monte Carlo 回报初始化规则动作的 Q 值，再让 Q-learning 在五类 B 对手和两种波动中探索。评估时仅当某个 Q 动作的估计优势超过预设门槛且该动作已有至少 25 次访问，才允许它替换动态规则动作。

这种初始化明确使用了动态规则作为策略先验。结果表示规则引导 Q 的改进表现，不能解释为无先验 Q-learning 从零学出了更优规则。

## 最终配对留出结果

最终候选使用每个训练种子 2,500 条示范轨迹和 10,000 个 Q-learning 回合。5 个训练种子在每个配对测试格内取平均；区间使用 250 个“B 对手 × 评估种子”格计算。

| 策略 | 正常波动成本 | 两倍波动成本 |
|---|---:|---:|
| 动态规则 | 38.364 bp | 35.802 bp |
| 双边自博弈 Q 的 A 策略 | 39.154 bp | 36.267 bp |
| 成本对齐的紧凑状态 Q | 38.971 bp | 36.009 bp |
| 规则先验双 Q，5 bp 门槛 | 38.379 bp | 35.806 bp |

最终 Q 与动态规则的成本差（Q 减规则）为：正常波动 **+0.015 bp**，近似 95% 区间 **[+0.002, +0.027]**；两倍波动 **+0.005 bp**，区间 **[−0.019, +0.029]**。正常波动下规则成本略低；高波动下没有显著差异。所有组完成率均为 100%，因为模拟器假设子单全额成交，并通过最低可行动作保障期限内可完成。

## 验证与训练量检查

在阈值验证种子 20261108 上，5 bp 门槛的配对差为：正常波动 +0.018 bp，95% 区间 [0.004, 0.033]；两倍波动 +0.018 bp，区间 [−0.009, 0.045]。在独立留出种子 20261109 上得到上表结果。

另将训练扩展到每个种子 30,000 回合和 5,000 条示范轨迹，在评估种子 20261110 上检查 1、2、5、10 bp 门槛。5 bp 门槛的成本差为正常波动 +0.024 bp [−0.0004, 0.0485]，两倍波动 +0.0095 bp [−0.024, 0.043]。10 bp 门槛基本复现动态规则，成本差为正常波动 +0.0003 bp [−0.0001, 0.0007]，两倍波动 +0.0001 bp [−0.0087, 0.0090]。

增加训练回合和动态规则示范没有使 Q 策略稳定优于规则。较高的偏离门槛令 Q 退回规则动作，成本因此趋于相同。当前模拟中，动态规则已具备与 Q 可用状态信息高度匹配的执行逻辑；Q 的非规则偏离没有显示可靠的额外成本收益。

## 产物与解释

- 最终留出比较：`matched_rule_q_comparison/`。
- 阈值验证与门槛扫描：`q_improvement_validation_20261108/`。
- 30,000 回合长训检查：`q_improvement_long_20261110/`。
- 每个目录的 `run_manifest.json` 记录训练配置、种子和代码哈希。

本轮结果支持“规则先验 Q 可以接近动态规则”，不支持“Q 已稳定超过动态规则”。要研究学习策略的额外价值，应在保持当前基准不变的基础上，另行预先设定部分成交、时变流动性或对手在线适应等环境扩展，再比较规则策略和 Q；不能因为当前结果不利而事后修改基准条件。
