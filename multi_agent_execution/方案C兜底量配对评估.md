# 方案 C 随机介入与训练评估

## 研究问题

本轮评估检验两件事：第一，在相同冻结 Q 检查点下，随机化的方案 C 能否减少终端兜底量并降低实际交易成本；第二，把随机 C 纳入 A、B 的 Q-learning 行为策略训练后，是否优于不使用 C 的纯 Q 模型。

这里的“兜底量”是第 60 步普通限价撮合结束后，由模拟收盘兜底成交的剩余股数。兜底只负责保证模拟母单按时完成。总完成率 100% 不是 Agent 自主完成率。

## 随机 C 如何参与 Agent 决策

每个时间步先由 Q 表提出原始动作。若母单没有落后当前线性执行进度，C 不介入；若落后，C 先依照执行阶段和缺口抽取是否介入，再随机产生动作下限、限价提高档数和数量追赶比例。最终动作是 Q 动作与 C 随机动作下限中的较积极者。数量追赶比例将 Agent 原本的子单量向“剩余股数 ÷ 剩余步数”目标随机靠近，限价加价仍受限价单和可见盘口撮合约束。

各阶段的基准介入概率、动作档位、加价档和数量比例如下。基准概率还会按进度缺口每多一个 TWAP 基准份额增加 3 个百分点，最多再加 20 个百分点；最终介入概率封顶为 98%。随机数使用独立于市场随机数的可复现随机流。

| 落后进度阶段 | 基准概率 | 随机动作下限及概率 | 随机报价加价档及概率 | 均匀抽样的追赶比例 |
|---|---:|---|---|---:|
| 70% 进度前 | 12% | 1:10%、2:55%、3:35% | 0:85%、1:15% | 10%–30% |
| 70%–85% | 32% | 2:12%、3:55%、4:33% | 0:62%、1:30%、2:8% | 25%–55% |
| 85%–95% | 60% | 3:38%、4:62% | 0:52%、1:28%、2:15%、3:5% | 40%–80% |
| 95% 之后 | 88% | 3:10%、4:90% | 0:24%、1:22%、2:18%、3:14%、4:10%、5:7%、6:5% | 70%–100% |

介入不是强制成交：动作 4 是有价格上限的 IOC，可能部分成交或未成交；被动单也继续受队列、订单流和可见卖盘影响。训练时 Q 表使用最终实际执行的动作档位更新，使随机 C 成为 Agent 行为策略的一部分，而不是仅在训练完成后加上的结果修饰。纯 Q 仍可通过默认模式复现。

## 实验一：同一冻结 Q 检查点的三组配对比较

设置为 5 个训练种子 × 每个场景 30 个评估种子，共每种方案、每个场景 150 个回合。三组使用同一批第 500 回合 A/B Q 检查点、相同市场路径、30 bp 单边手续费、相同限价订单簿和终端兜底。

| 场景 | 方案 | A 兜底均值 | B 兜底均值 | A 成本 (bp) | B 成本 (bp) |
|---|---|---:|---:|---:|---:|
| 正常波动 | 纯 Q | 64,470 | 62,937 | 51.178 | 50.841 |
| 正常波动 | 确定性 C | 42,730 | 42,558 | 45.652 | 45.623 |
| 正常波动 | 随机 C | 50,216 | 49,319 | 47.156 | 46.936 |
| 两倍波动 | 纯 Q | 63,933 | 60,640 | 49.296 | 48.391 |
| 两倍波动 | 确定性 C | 44,107 | 39,405 | 44.356 | 43.343 |
| 两倍波动 | 随机 C | 48,748 | 48,225 | 45.066 | 45.061 |

在冻结 Q 对照中，随机 C 相对纯 Q 在四个机构/场景组合里都同时降低兜底量和平均成本。相对纯 Q，正常波动下 A、B 的平均兜底分别少约 14,254、13,618 股，成本分别下降约 4.022、3.905 bp；两倍波动下分别少约 15,185、12,415 股，成本下降约 4.230、3.331 bp。确定性 C 的改善更大，但随机 C 保留了 Agent 原始动作并具有阶段与参数随机性。

## 实验二：随机 C 纳入双边 Q-learning 训练

随机 C 训练采用 5 个独立训练种子、每个 500 回合，并在第 0、100、200、300、400、500 回合保存检查点；纯 Q 对照使用相同训练预算、训练种子、市场随机种子、30 bp 手续费和奖励参数。最终 A、B 检查点在两种波动环境下进行相同评估种子配对比较，每个场景 150 个对局。

| 场景 | Agent | 纯 Q 兜底均值 | 随机 C 训练兜底均值 | 兜底减少 | 纯 Q 成本 (bp) | 随机 C 训练成本 (bp) | 成本降低 (bp) |
|---|---|---:|---:|---:|---:|---:|---:|
| 正常波动 | A | 64,470 | 53,587 | 10,883（16.9%） | 51.178 | 48.081 | 3.097 |
| 正常波动 | B | 62,937 | 52,643 | 10,295（16.3%） | 50.841 | 47.785 | 3.056 |
| 两倍波动 | A | 63,933 | 52,684 | 11,248（17.6%） | 49.296 | 46.230 | 3.066 |
| 两倍波动 | B | 60,640 | 53,256 | 7,384（12.2%） | 48.391 | 46.362 | 2.029 |

所有组合的配对平均差都朝同一方向：随机 C 训练降低了兜底股数和成本。该结果说明，在当前合成环境与训练预算下，C 参与行为策略并按最终动作学习，比纯 Q 基线更能提前执行订单；但随机 C 训练的改善幅度小于冻结检查点上使用确定性 C 的评估结果。

## 结论与限制

- 当前实验支持“随机 C 在本模型和本组种子下优于纯 Q 基线”的有限结论，不支持“随机 C 优于确定性 C”或“对真实市场必然更优”的结论。
- 随机 C 训练仍平均留下约 5.1 万–5.5 万股由终端兜底完成。它减少了兜底量，但没有消除兜底依赖；100% 完成率来自环境收盘兜底。
- 平均成本是模型内实际成交、手续费和冲击的经济成本，不包含训练奖励中的进度惩罚与终局残余惩罚。
- 订单流、盘口队列、可见深度及收盘兜底冲击均是合成假设，未使用真实逐笔行情校准。不能把结果表述为实盘收益预测。
- 默认 `--deadline-c-mode none` 保留纯 Q 结果；只有显式使用 `--deadline-c-mode stochastic` 才训练并评估随机 C 策略，两个结果保存在不同目录，避免覆盖基线。

## 复现

随机 C 双边训练及交叉评估：

```powershell
python .\run_experiment.py --episodes 500 --training-runs 5 --eval-seeds 30 --checkpoint-interval 100 --seed 20261107 --fee-bps 30 --schedule-deficit-penalty-bps 10 --terminal-unfilled-penalty-bps 1000 --deadline-c-mode stochastic --output-dir .\outputs\advanced_self_play_stochastic_c_500x5x30
```

在既有冻结 Q 检查点上比较纯 Q、确定性 C 与随机 C：

```powershell
python .\compare_deadline_c_overlay.py --checkpoint-dir .\outputs\penalty_comparison_shaped_500x5x30 --output-dir .\outputs\stochastic_c_policy_comparison_current_model
```

逐回合配对明细保存在以上输出目录的 `cross_play_raw.csv`、`c_overlay_raw.csv` 与 `c_overlay_paired_differences.csv` 中；对应 `run_manifest.json` 记录配置和策略模式。
