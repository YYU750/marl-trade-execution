# 多智能体交易执行模型假设说明

## 1. 文件用途与主模型范围

本文说明当前课程项目主模型采用的研究假设，供论文、汇报和代码复现使用。主模型采用 **A、B 双边同步 Independent Q-learning，并为每个 Agent 配置学习型方案 C 决策头**。市场参与率固定使用中档设定，目标为 **A+B 合计 25%**。

本文只定义当前主要模型的 25% 参与率假设，不展开低、高参与率档位。后续如需进行参与率压力测试，应作为独立实验加入，并与本文主模型结果分开报告。

需要区分题目背景与建模选择：收盘前有限时间执行大额买入任务是研究背景；30 秒时间步、参与率口径、订单簿参数、强化学习参数及收盘兜底方式均是本项目为了构建可运行实验而设置的假设，不是由真实市场数据估计出的事实。

## 2. 交易任务与时间设定

| 假设 | 主模型设定 | 说明 |
|---|---:|---|
| 交易方向 | 买入 | A、B 均执行买入母单 |
| A 的母单 | 100,000 股 | 每个模拟回合开始时固定 |
| B 的母单 | 100,000 股 | 与 A 数量相同，采用对称任务设定 |
| 执行窗口 | 30 分钟 | 从回合开始到模拟截止 |
| 时间步长 | 30 秒 | 将窗口划分为 60 个决策步；这是项目的时间离散化选择 |
| TWAP 基准份额 | 约 1,666.67 股/步/机构 | 母单数量除以 60 步，用作进度参照和动作数量单位 |
| 初始中间价 | 100 | 合成价格序列的起点，不对应特定证券的真实价格 |

模型不考虑卖出任务、多个证券之间的资金配置、不同母单规模或不同截止时间。A、B 的目标方向和订单规模相同，便于聚焦双方在共同市场中的执行互动。

## 3. A、B 两个 Agent 的行为假设

1. **两个 Agent 都自主决策。** A、B 各自学习自己的策略，不共享 Q 表，也没有中央控制器统一指定联合动作。
2. **双方同时决策。** 每步开始时，A、B 使用同一份交易前市场快照各自选动作；任何一方都看不到对方本步尚未执行的动作。
3. **双方目标相同。** 两边都希望在期限内买完母单，并控制实际执行成本。因此，模型是有共同交易方向和市场竞争的策略互动，不是严格零和博弈。
4. **信息有限。** Agent 可观察自身剩余母单、当前市场价格、自身活动挂单与队列状态，以及对手上一时间步的实际成交量等离散状态；它看不到未来价格冲击、未来卖方订单流或对手本步动作。
5. **A、B 结构对称但策略独立。** 两边使用相同动作定义、状态设计和奖励口径，但各自维护 Q 值与访问次数，训练随机流也独立。

## 4. 中档 25% 市场参与率假设

### 4.1 目标比例的定义

主模型的 25% 是按计划母单量与外生背景市场成交量计算的目标比例：

**目标参与率**

$$
\rho_{AB}^{\mathrm{plan}}
= \frac{Q_A+Q_B}{Q_A+Q_B+V_{\mathrm{bg}}^{\mathrm{expected}}}
= \frac{200{,}000}{200{,}000+600{,}000}
= 25\%.
$$

因此，中档设定对应：

- A+B 计划母单总量：200,000 股；
- 30 分钟背景市场成交量期望：600,000 股；
- 背景成交量期望：平均约 10,000 股/30 秒步。

### 4.2 背景成交量的生成

背景成交量由均值保持的对数正态随机过程生成，默认对数波动参数为 0.25，并独立于 A、B 的实际成交。该变量用于表示其他市场参与者带来的总体交易活动，不是由数个真实第三方 Agent 逐笔提交并撮合出来的成交量。

### 4.3 参与率的报告口径

主要参与率口径只统计 A、B 在普通限价订单簿中的 Maker/Taker 实际成交：

**普通盘口实现参与率**

$$
\rho_{AB}^{\mathrm{ordinary,realized}}
= \frac{V_{AB}^{\mathrm{ordinary}}}
       {V_{AB}^{\mathrm{ordinary}}+V_{\mathrm{background}}}.
$$

其中，$V_{AB}^{\mathrm{ordinary}}$ 表示 A、B 在普通盘口的实际成交量，$V_{\mathrm{background}}$ 表示背景市场成交量。

收盘兜底成交不计入主要口径。若另行报告包含兜底的比例，必须明确标注“含终端兜底”；由于兜底会补足母单，该比例可能机械地接近按计划设定的 25%，不能当作 Agent 盘中自主成交的证据。

## 5. 市场价格与冲击假设

| 参数 | 主模型值 | 解释 |
|---|---:|---|
| 初始中间价 | 100 | 合成价格起点 |
| 单边半价差 | 2 bp | 买卖两侧合计合成价差约 4 bp |
| 最小价位 | 1 bp | 报价变化的最小单位 |
| 一分钟波动率 | 2.5 bp | 外生价格冲击的标准差参数 |
| 30 秒步外生冲击标准差 | 约 1.77 bp | 按时间平方根缩放：$2.5 \times \sqrt{0.5} \approx 1.77\ \mathrm{bp}$ |
| 暂时冲击系数 | 0.35 bp/基准份额 | 用于成交成本的合成冲击参数 |
| 永久冲击系数 | 0.20 bp/基准份额 | 依据 A、B 双方实际成交量影响下一步中间价 |

每步外生价格冲击设为均值为零的高斯随机变量。主训练在正常波动参数下进行；当前评估代码另有两倍波动场景。中间价由外生冲击和双方实际成交引发的永久冲击共同更新：

**中间价更新**

$$
P_{t+1}
= P_t \times \left(1 + \frac{\epsilon_t+I_t^{\mathrm{perm}}}{10{,}000}\right).
$$

其中，$P_t$ 是当前中间价，$\epsilon_t$ 是本步外生价格冲击，$I_t^{\mathrm{perm}}$ 是本步由 A、B 实际成交产生的永久冲击，数值单位为 bp。

永久冲击根据实际成交量计算，不根据 Agent 提交的未成交数量计算。A、B 都是买方，因此在当前设定下，成交量增加会产生向上的永久价格影响。上述价格过程和冲击系数是可复现的合成假设，尚未由某个真实证券的历史行情或逐笔成交数据校准。

## 6. 合成订单簿与撮合假设

模拟器采用简化的事件驱动限价订单簿。其主要参数如下：

| 参数 | 主模型值 |
|---|---:|
| 卖方主动订单到达 | 每步 Poisson 均值 1.5 笔 |
| 单笔卖方订单规模均值 | 0.70 个 TWAP 基准份额 |
| 卖方订单数量波动 | 对数正态参数 0.55 |
| 七档可见卖盘平均深度 | 0.80、0.55、0.40、0.30、0.22、0.16、0.12 个基准份额 |
| 可见队列深度波动 | 对数正态参数 0.35 |
| 被动买单前方平均外部队列 | 0.12、0.65、1.10 个基准份额，对应不同报价档 |
| 被动挂单有效期 | 4 步，即约 2 分钟 |

主要撮合规则为：

- 被动买单根据价格优先和队列前方数量等待卖方主动订单流；卖方流量先消耗队列，剩余部分才可能成交本方订单。
- IOC 限价单按其限价范围消耗七档合成卖盘；可部分成交，限价之外的卖盘不可成交，剩余 IOC 数量立即撤销。
- 任何订单的提交量都不自动视为成交量。只有订单簿实际撮合的数量才减少母单。
- 重新报价会撤销原挂单并重新排队；挂单过期、IOC 余量、截止时活动挂单等撤单数量单独记录。
- A、B 同价订单的先后关系用预生成的随机优先次序处理。

在相同随机种子下，策略比较共享相同外生冲击、随机创新和初始事件设定；但 A、B 的实际成交会改变后续价格，所以不同策略的完整价格路径不必完全一致。

## 7. 普通 Q 头与学习型 C 头的假设

每个 Agent 有两个独立的表格型决策头。

### 7.1 普通订单动作 Q 头

普通头在五种基础动作中选择：保持现有挂单或等待、深档被动买单、最佳买价挂单、价差内被动报价、可成交限价 IOC。动作规模按每步 TWAP 基准份额的 0.5、1、1.5 或 2 倍设置；IOC 有报价上限，不是无价格限制的市价单。

普通头的离散状态包含时间、执行进度、价格偏离、对手上一时段成交量，以及自身挂单价格档、剩余挂单量、队列前方数量和订单年龄等信息。

### 7.2 学习型 C-Q 决策头

C 头不使用固定时钟节点自动加急。只有当剩余母单超过当前剩余时间对应的线性执行计划时，系统才开放 C 头的加急选择。落后时，C 头有 **no-C**，以及 12 种报价和追赶量组合：

- 报价：在基准 IOC 限价上增加 1、3 或 6 个 tick；
- 额外追赶量：当前进度缺口的 0%、25%、50% 或 100%。

非 no-C 动作会把普通订单动作下限提高到 IOC，并在基准 IOC 子单数量上增加所选比例的进度缺口；数量不会超过剩余母单。基准 IOC 数量为 2 个 TWAP 基准份额。加急选择仍需通过合成盘口实际撮合，因此 C 头不能直接把提交量记成成交量。

C 头的状态包含准确时间步、进度落后比例档、相对初始价格的偏离档、自身挂单状态和对手上一时段成交量档。第 42、51、57 步（约 20 分 30 秒、25 分钟、28 分钟）只作为方案讨论中的参照，不是代码中的固定触发点。

## 8. 奖励、成本与按时完成假设

### 8.1 学习奖励

实际成交的含费实施缺口形成基础奖励；低于线性执行进度的步会增加进度惩罚；终局时，未完成或交给终端兜底的母单余量会受到额外惩罚。当前默认惩罚系数为：

- 每步进度缺口惩罚系数：10 bp；
- 终局残余/兜底量惩罚系数：1,000 bp。

进度惩罚和终局惩罚是强化学习的训练信号，不计入实际经济交易成本。

### 8.2 经济成本

实际成本按成交价格偏离初始中间价的实施缺口、实际手续费和可能存在的未完成机会成本统计。单边手续费设为 **30 bp，即成交名义金额的 0.3%**。硬完单模式下，兜底成交同样按其假设价格及手续费计入成本，并单独报告兜底股数和成本贡献。

### 8.3 终端完单约束

当前主模型使用 autonomous 硬完单设置：第 60 步普通撮合后，如仍有剩余母单，环境按合成收盘兜底机制将其结清。公式按以下顺序计算：

$$
\begin{aligned}
I_{\mathrm{backstop}}(q,b)
&= 1 \times \sqrt{\frac{q}{b}}
 + 0.35 \times 1.0 \times 0.5 \times \frac{q}{b}, \\
P_{\mathrm{backstop}}
&= P_t \times \left[1 + \frac{s_{\mathrm{half}}+I_{\mathrm{backstop}}(q,b)}{10{,}000}\right].
\end{aligned}
$$

其中，$q$ 是待兜底数量，$b$ 是每步 TWAP 基准份额，$s_{\mathrm{half}}=2\ \mathrm{bp}$ 是单边半价差。该深层流动性曲线是程序为满足按时完成设定而加入的教学假设，并非真实市场保证存在的对手盘。

因此，主模型的总完成率为 100% 是环境兜底约束带来的结果。Agent 的盘中能力应通过普通盘口成交量、兜底量和总成本拆分评价，不能用总完成率单独证明 Agent 学会了全部执行。

## 9. 学习训练与主结果复现设定

| 参数 | 当前主模型设定 |
|---|---:|
| Q-learning 类型 | A、B 同步 Independent Q-learning；每个 Agent 内含普通 Q 头和 C-Q 头 |
| 学习率 $\alpha$ | 0.15 |
| 折扣因子 $\gamma$ | 0.98 |
| 探索率 | 从 0.35 线性下降至 0.05 |
| 独立训练种子 | 5 |
| 每个训练种子回合数 | 500 |
| 检查点 | 0、100、200、300、400、500 回合 |
| 每个交叉评估单元配对种子数 | 30 |
| 主训练市场状态 | 正常波动 |
| 冻结策略评估 | 正常波动与两倍波动 |

检查点交叉对局中，策略被冻结后互相组合评估；评估期间不继续更新 Q 表。候选集最佳反应只是在已保存检查点集合中寻找相对低成本策略，不代表完整策略空间的全局最优，也不构成纳什均衡证明。

## 10. 假设的适用边界

以下内容是本模型的简化或限制，报告结果时应明确说明：

1. 当前模型是单资产、单方向买入任务，不包含真实股票的完整订单簿数据。
2. 背景市场成交量是独立的总体活动代理；它没有由真实第三方订单逐笔生成，也不直接参与订单簿队列撮合。
3. 卖方主动订单、队列、可见卖盘和价格冲击按指定随机分布构造，尚未用真实市场数据校准。
4. 订单簿仅近似价格优先、队列消耗和有限档位深度，不覆盖隐藏流动性、完整交易所规则、延迟、撤单竞争等全部现实机制。
5. 终端兜底是一项人为设定的合成流动性假设；不能外推为现实市场一定可以在截止时以对应价格完成交易。
6. A、B 目标同向、规模相同且使用相同的奖励结构，因此结论只反映该对称买入场景下的策略互动。
7. 参与率 25% 是按计划母单和期望背景成交量设定的场景参数，不是 Agent 自主达到的绩效，也不是现实市场测得的固定份额。

因此，本模型适合用于展示 Agent 如何在一个可控、可复现的仿真环境中学习订单执行与加急决策；结论应表述为“在当前模型假设下观察到”，而不应直接写成真实市场规律或实盘效果。
