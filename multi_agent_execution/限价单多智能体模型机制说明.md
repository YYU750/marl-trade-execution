# 限价单多智能体交易执行模型机制说明

版本：限价单撮合版（Independent Q-learning 双边同步自博弈）  
适用代码：`run_advanced_self_play.py`、`limit_order_book.py`、`schedule_aware_q.py`  
执行窗口：30 分钟；每步 30 秒，共 60 步

## 1. 模型目标与研究边界

模型模拟基金 A 和基金 B 在收盘前执行买入母单的过程。两家机构各有 100,000 股待买订单，同时考虑执行成本、订单完成进度和对方此前的成交活动。A、B 使用各自独立的表格型 Q-learning 策略；每一步同时选择订单动作，环境再统一处理订单和价格反馈。

本版把原有“提交多少子单就视为成交多少”的假设改为限价单撮合。订单要先报出限价；是否成交、成交多少，取决于价格、显示队列前方数量、市场订单流和可见卖盘深度。未成交母单允许留到窗口结束，因此完成率是实验结果，不由环境预先设成 100%。

市场是教学用途的合成订单簿，不使用真实逐笔行情校准，也不连接券商账户或真实交易接口。所有盘口深度、订单流和冲击参数都属于可复现的模拟假设。

## 2. 参与者和信息边界

| 组成 | 职责 | 可观察信息 |
|---|---|---|
| Agent A | 决定自己的买单报价、数量和是否保留已有挂单；独立更新 A 的 Q 表 | 当前中间价、执行进度、对手上一步实际成交量、A 自己的挂单和队列状态 |
| Agent B | 与 A 同时决策；独立更新 B 的 Q 表 | 当前中间价、执行进度、对手上一步实际成交量、B 自己的挂单和队列状态 |
| 市场环境 | 产生外生订单事件，按限价和队列撮合，计算费用、成交和价格变化 | 本步双方订单、显示盘口深度、随机订单流和当前市场状态 |
| 评估器 | 冻结训练策略，安排检查点交叉对局并统计结果 | 冻结的 Q 表、配对随机种子和实验场景 |

双方先用同一交易前中间价各自选动作，选择完成后才提交到共同撮合环境。任何一方在决策时看不到对手本步的新动作。市场只向下一步状态反馈已经发生的成交量，不把提交量冒充实际成交量。

## 3. 一回合的运行顺序

每回合开始时，A、B 各持有 100,000 股母单，参考中间价为 100。每个 30 秒时间步按以下顺序运行：

1. **更新旧挂单。** 挂单达到有效期后撤销；若中间价变化使旧买单变成可成交限价单，则按当前卖盘检查成交。
2. **生成观察。** 双方看到相同的交易前价格、时间和外生波动状态，各自另外看到自己的剩余母单、挂单余量、队列位置和挂单年龄，以及对手上一步实际成交量。
3. **同步选动作。** 双方从各自 Q 表选择动作；训练期间使用 epsilon-greedy 探索。此时双方还未提交本步订单。
4. **撤旧与挂新。** 动作 0 保留现有单或继续等待；动作 1–4 会撤销本方旧单，再按新价格和数量提交新子单。重新报价会重新排队。
5. **撮合主动限价单。** 可成交限价单按价格优先、同价随机时间优先消耗两档可见卖盘。成交量不足时只部分成交；动作 4 的 IOC 未成交余量立即撤销。
6. **撮合被动挂单。** 卖方主动订单流先消耗买单队列前方的显示数量，剩余流量才可能触发本方订单成交。单笔订单可以部分成交，剩余部分继续留在队列。
7. **更新市场和母单。** 仅实际成交量减少母单。环境按实际成交更新手续费、暂时/永久价格冲击、剩余订单和对手上一期成交量。
8. **计算奖励并更新 Q 表。** A、B 的动作都已确定且共同市场转移完成后，环境分别计算奖励并更新双方各自的 Q 表。

训练时双方策略都在变化，所以单个 Agent 面对的环境具有非平稳性。检查点交叉评估会冻结策略，避免评估期间继续改写 Q 表。

## 4. 状态表示

新 Q 状态编码为 `schedule_aware_limit_order_v2`，由以下离散特征组成：

| 特征 | 编码规则 |
|---|---|
| 时间阶段 | 每 10 步一档，共 6 档 |
| 执行进度 | `剩余母单 / (TWAP 基准份额 × 剩余步数)`；阈值为 0.95、1.10、1.40，共 4 档 |
| 价格偏离 | 当前中间价相对初始价；低于 −2bp、−2 至 +2bp、高于 +2bp，共 3 档 |
| 对手上一期成交量 | 小于或不小于一个 TWAP 基准份额，共 2 档 |
| 自己的限价档位 | 无挂单、深档被动、最佳买价、价差内、当前可成交，共 5 档 |
| 自己的挂单余量 | 不超过或超过一个 TWAP 基准份额，共 2 档 |
| 自己的队列前方数量 | 小于或不小于一个 TWAP 基准份额，共 2 档 |
| 自己的订单年龄 | 不超过 1 步或至少 2 步，共 2 档 |
| 是否最后一步 | 否/是，共 2 档 |

无挂单时，订单相关特征编码为“无挂单”状态。队列位置和挂单年龄只描述本方子单；模型不使用对手的当前订单位置，也不预测对手未来动作。

## 5. 动作和订单生命周期

每家母单为 100,000 股，窗口 60 步，因此 TWAP 基准份额约为 1,666.67 股。Q 表仍有 5 个动作，含义改为：

| 动作编号 | 目标数量 | 订单动作 | 限价位置 |
|---:|---:|---|---|
| 0 | 0 | 保留已有单；没有挂单时等待 | 不新报价格 |
| 1 | 0.5 × 基准份额 | 挂深档被动买单 | 最佳买价下方 1 个价位 |
| 2 | 1.0 × 基准份额 | 挂最佳买价 | 当前最佳买价 |
| 3 | 1.5 × 基准份额 | 提高报价等待被动成交 | 最佳买价上方 1 个价位、仍在价差内 |
| 4 | 2.0 × 基准份额 | 可成交限价 IOC | 限价上限为最佳卖价上方 1 个价位 |

当中间价为 100、半价差为 2bp、最小价位为 1bp 时，最佳买价约 99.98，最佳卖价约 100.02；深档买价约 99.97，价差内买价约 99.99，动作 4 的最高限价约 100.03。具体值随中间价变动。

被动挂单最多保留 4 个时间步，即 2 分钟。动作 0 可维持它并保留队列优先级；选择其他报价动作会取消旧单并重新进入队列。动作 4 是 IOC：立即扫过限价范围内最多两档可见卖盘，成交后取消未成交余量。被动单如果因价格移动变成可成交单，会先尝试消耗卖盘，剩余未成交部分可继续留在簿上。

**提交数量不是成交数量。** 新单会记录提交股数；只有撮合事件确认成交的股数才从母单剩余量中扣除。重新报价、有效期到期、IOC 余量及窗口结束未成交挂单会分别记为撤单。

## 6. 合成订单簿与成交概率

订单簿参数集中在 `SyntheticLOBConfig`。默认设置如下：

| 参数 | 默认值 | 作用 |
|---|---:|---|
| 最小价位 | 1bp | 计算价差内报价和卖盘价格档位 |
| 挂单有效期 | 4 步 | 被动挂单超过 2 分钟后撤销 |
| 被动队列深度均值 | 0.12、0.65、1.10 个基准份额 | 估计价差内、最佳买价及更深买价前方的外部数量 |
| 每步卖方主动订单数 | Poisson 均值 1.5 笔 | 产生冲击买方队列的随机卖单事件 |
| 单笔卖单均值 | 0.70 个基准份额 | 配合对数正态波动生成卖方主动订单数量 |
| 卖盘前两档深度均值 | 0.80、0.55 个基准份额 | 限制动作 4 一步最多可以扫到的数量 |

新买单队列前方数量由对应价格层及更优价格层的显示深度、以及已经排在前面的本方/对手子单共同构成。卖方主动订单先冲击更高买价，再按同价时间优先级处理；只有队列前方数量被消耗后，本方挂单才开始成交。因此较高报价通常排得更靠前，较大的队列前方数量则降低当前订单成交机会。

卖方事件量、队列深度和两档卖盘深度均逐步随机变化。相同评估种子会预生成同一外生市场事件带，供不同冻结策略组合配对使用；策略各自成交量不同，仍会形成不同的内生价格路径。

## 7. 成交价格、手续费和价格冲击

当前主要环境参数：初始中间价 100、半价差 2bp、单边手续费 30bp、每分钟外生波动标准差 2.5bp。两倍波动压力场景将外生波动标准差乘 2。

- 被动成交按本方限价成交，交易手续费按实际成交名义金额计收。
- 主动成交在最佳卖价及第二档卖价成交；暂时冲击只按实际主动成交量计算，不对未成交报价收费。
- 永久冲击按当步 A、B 实际成交量合并计算，进入下一步中间价。
- 外生价格冲击按 30 秒步长的波动率平方根缩放；临时和永久冲击按步长分钟数缩放。

对 Agent i，报告成本按母单金额归一化：

```text
总成本 = 实际成交部分毛实施缺口
       + 实际成交手续费
       + 未成交母单的终局机会成本
```

实际成交部分以初始中间价为基准；未成交部分的机会成本使用窗口结束时的中间价。报告同时列出完成率和未完成股数，避免把未买到的股票误当成节省成本。Q 学习奖励中的终局未完成惩罚另按“未完成比例 × 1,000bp”计算；该学习惩罚不加入报告的 `cost_bps` 指标。

## 8. Q-learning 训练和冻结评估

A、B 分别维护一张 Q 表，使用 Independent Q-learning。当前配置为学习率 `α=0.15`、折扣因子 `γ=0.98`、探索率从 `0.35` 线性降至 `0.05`。训练中所有订单动作都允许选择；代码不再用“最低可提交量”假装保证完成。

当步奖励按真实成交股数及含费实施缺口计算。终局奖励再扣除未成交母单惩罚，并计入未成交机会成本。下一状态最大 Q 值仅从已尝试动作中选择，以防未探索动作的零初值高估。即使动作没有成交，也仍会记录这次动作和状态转移。

默认训练规模为 5 个独立训练种子、每个 500 回合，每 100 回合保存检查点。训练结束后，对 A、B 检查点全交叉，在正常和两倍波动场景中使用配对种子评估。交叉对局冻结策略，不更新 Q 表。后悔值只相对已保存的有限检查点集合计算，不能解释成全局最优或纳什均衡证明。

## 10. 当前试跑观察与解释限制

当前机制检查运行使用 1 个训练种子、500 回合和 3 个配对评估种子。最终检查点完成率在该小样本中仍偏低，约为正常波动 A 21.0%、B 15.7%，两倍波动 A 19.9%、B 14.3%。这表明当前 Q 策略和合成订单流设定下有大量母单未成交；不能据此声称策略已经能完成收盘前买入任务，也不能根据少量种子比较 A/B 优劣。高波动下出现负成本，可能源于窗口结束价低于初始价且订单未完成，须结合完成率解读。

正式研究需要增加训练随机种子和评估种子，并对订单流、队列深度、卖盘深度进行合理校准或敏感性分析。旧版 `outputs/advanced_self_play/` 及 `run_matched_rule_q_comparison.py` 使用提交即成交环境，不能与本版限价单结果直接拼表；规则基准若要比较，必须在同一个限价单撮合器中重新实现并运行。
