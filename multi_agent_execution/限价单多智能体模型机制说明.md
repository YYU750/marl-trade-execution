# 限价单双边同步 Q-learning 交易执行模型：完整运行机制

- **版本**：事件驱动限价单 + 方案 C 硬完单版
- **适用代码**：run_experiment.py、run_advanced_self_play.py、limit_order_book.py、schedule_aware_q.py、run_standard_benchmark.py
- **研究路线**：路线 A——A、B 双边同步 Independent Q-learning
- **文档用途**：机制介绍、课程汇报、研究设计说明和代码复现
- **当前默认配置**：30 分钟执行窗口、每 30 秒一个时间步，共 60 步

当前主入口默认 `--completion-mode c`。本文中的 C 方案内容覆盖早期“无强制完成”的限价单机制说明；`--completion-mode none` 只保留为显式对照模式。

## 1. 模型摘要

本模型模拟两家机构 A 和 B 在收盘前执行买入母单的过程。每家机构需要买入 100,000 股，在 30 分钟内反复观察市场并决定如何报价。A、B 都是学习型交易执行 Agent，各自维护一张独立的表格型 Q 表。每个时间步开始时，两家 Agent 根据同一份交易前市场快照、自己的母单进度、自己的未完成子单，以及对手上一时间步的实际成交量，同时选择下一步动作。动作进入同一合成订单簿后，由环境根据价格优先、队列前方数量、可见卖盘深度和随机卖方订单流撮合。

模型明确区分了三件事：

1. **母单目标**：每家机构计划在窗口内买入的总股数。
2. **子单提交量**：Agent 本步新报出的限价单数量。
3. **实际成交量**：订单簿确认撮合的数量。

只有实际成交才会减少剩余母单。提交数量不会自动变成成交数量，限价单可以部分成交、暂时不成交、被替换或过期。C 方案在早期保留 Q-learning 自主报价；若执行进度落后，则在截止前逐段提高最低动作和报价上限；到第 60 步仍有剩余母单时，环境按公开的合成价格曲线执行收盘强制成交。因此 C 模式 100% 完成是硬约束的设计结果，不是 Agent 单独学出来的能力。

C 模式把强制成交数量及其成本贡献单独记录。其目标是满足题目完单约束，同时让 Agent 尽量在前段以低冲击的限价单成交、减少最后的兜底数量。兜底使用合成深层流动性，不代表真实交易所保证能按模型价格成交。无强制完成对照需显式运行 `--completion-mode none`，并与 C 结果分开分析。

本模型的主要研究对象是：在订单无法保证即时成交、市场价格受到双方实际交易影响的条件下，两个独立学习的执行策略如何形成互动；训练过程是否稳定；训练不同阶段的策略互相对局时成本和完成率如何变化；面对有限候选策略集合时，某个检查点是否存在更低成本的候选最佳反应。

这是教学用途的合成订单簿模拟器，不连接真实交易账户，不接收真实行情，也不复刻完整交易所撮合规则。队列深度、订单流、价格冲击和成交概率都是明示的模拟假设。

## 2. 研究路线与概念边界

### 2.1 主模型：双边同步 Independent Q-learning

A 和 B 都使用 Q-learning，但两边拥有各自的：

- 状态访问记录；
- 动作访问次数；
- Q 值表；
- 探索随机数流；
- 学习更新。

Agent 不共享 Q 表，也没有中央控制器替它们联合选择动作。每个 Agent 根据自己能看到的信息独立决策。双方的交易会通过共同订单簿、共同卖方订单流以及共同的价格冲击影响彼此，这构成模型中的策略互动。

这里的“同步”指：A、B 在同一时间步基于同一交易前快照先完成各自动作选择，双方动作都确定后，市场环境再统一处理订单和价格转移。随后，环境分别计算两边奖励，再更新各自的 Q 表。它不表示两张 Q 表被合并，也不表示使用了集中式联合策略。

### 2.2 算法扩展：规则引导 Double Q 与主模型分开

代码库还保留了规则引导 Double Q、固定规则对手和历史提交即成交基准等实验路径。它们属于算法对照或历史版本，不是本说明中的双边限价单自博弈主实验。

写报告时应区分：

- **路线 A**：A、B 同时学习，研究双边策略互动、检查点交叉对局和候选最佳反应。
- **路线 B**：一个学习者面对固定规则对手，研究学习算法相对动态规则等基准的表现。

路线 B 的算法、撮合口径或结果不能直接当成路线 A 的双边学习结果。若要比较路线 A 与其他规则方法，必须让所有策略使用相同的限价单环境、成本口径和随机种子设计。

## 3. 研究对象、交易任务和时间单位

### 3.1 机构与母单

| 项目 | 设定 |
|---|---|
| 资产 | 单一合成股票 |
| 交易方向 | A、B 均执行买入 |
| 每家母单 | 100,000 股 |
| 执行窗口 | 30 分钟 |
| 时间步 | 30 秒 |
| 每回合步数 | 60 步 |
| 初始中间价 | 100 个价格单位 |
| 初始半价差 | 2 bp |
| 最小报价档位 | 1 bp |
| 默认单边手续费 | 30 bp，即名义成交额的 0.3% |

bp 为基点，1 bp 等于 0.01%。因此 30 bp 等于 0.3%。如果一方在参考价格 100 时完整买入 100,000 股，名义金额为 10,000,000，按 30 bp 单边费率计算的手续费约为 30,000 个货币单位。实际模型只对实际成交部分收取手续费；未成交部分不产生交易手续费。

30 分钟是研究任务窗口。30 秒是模型内部的决策粒度，是本项目采用的实验设计，不是课程题目指定的交易频率。

### 3.2 时间与波动缩放

配置中的波动率 2.5 bp 表示每分钟外生价格冲击的标准差。每步长 30 秒，即 0.5 分钟，因此单步外生冲击标准差为：

$$
\sigma_{\text{step}}
= 2.5\sqrt{0.5}
\approx 1.768\text{ bp}.
$$

两倍波动场景把该标准差再乘以 2，得到约 3.536 bp。训练默认只在正常波动场景进行；训练完成后，冻结检查点在正常波动和两倍波动场景评估。当前限价单状态编码没有把波动率作为单独状态维度，因此策略在两倍波动下不会因为显式的“高波动标签”切换策略，它只是面对不同的价格冲击分布进行样本外评估。

## 4. 系统组成及其职责

| 模块 | 主要职责 |
|---|---|
| Agent A | 观察 A 自身状态与对手上期成交量，选择买入子单动作，更新 A 的 Q 表 |
| Agent B | 与 A 同步决策，观察 B 自身状态与 A 上期成交量，独立更新 B 的 Q 表 |
| 合成订单簿 | 管理活动子单、限价、队列前方量、可见卖盘和撮合结果 |
| 市场事件带 | 预生成逐步外生价格冲击、卖方主动订单流、队列深度、卖盘深度和同价优先顺序 |
| 价格环境 | 根据外生冲击与双方实际成交造成的永久冲击更新下一步中间价 |
| 奖励与会计模块 | 计算逐步学习奖励、手续费、实施缺口、终局未完成机会成本和完成率 |
| 检查点评估器 | 保存训练中间策略，冻结策略组合，使用配对随机种子进行交叉对局与汇总 |

环境、训练器和 Agent 之间的大致数据流如下：

    外生事件带 + 当前市场状态
                 ↓
    生成 A、B 各自观察（共享交易前价格，各自私有订单状态）
                 ↓
        A 选动作              B 选动作
              ↘               ↙
          限价单提交、撤单与队列登记
                       ↓
          可成交限价单扫卖盘 + 被动订单队列撮合
                       ↓
          实际成交、手续费、暂时冲击与奖励
                       ↓
           永久冲击和外生冲击更新下一步价格
                       ↓
          A 更新自己的 Q 表，B 更新自己的 Q 表

## 5. 每个 Agent 可以看到什么

每一步开始时，A、B 使用相同的交易前中间价和相同的当前时点，但各自收到自己的 Observation。主要字段如下：

| 观察字段 | 含义 |
|---|---|
| t | 当前时间步编号 |
| remaining | 本方母单尚未成交的股数 |
| mid | 当前交易前中间价 |
| initial_mid | 回合开始时的参考中间价 |
| opponent_previous_qty | 对手上一时间步的实际成交股数 |
| base_slice | 每家母单按时间均匀划分得到的基准份额 |
| horizon | 全部时间步数 |
| volatility_bps | 当前场景的单步外生波动率 |
| open_order_qty | 本方当前活动子单的未成交股数 |
| queue_ahead | 本方当前活动子单前方的估计排队数量 |
| limit_price | 本方当前活动子单限价 |
| order_age_steps | 本方当前活动子单已经存续的步数 |

### 5.1 信息隔离

决策时，Agent 不直接看到：

- 对手本时间步刚选择的动作；
- 对手本时间步刚提交的子单数量；
- 对手当前活动订单的完整限价和队列；
- 未来随机价格冲击；
- 未来卖方主动订单流；
- 下一步真实成交量。

对手上一时间步的**实际成交量**会在下一步作为一项状态输入。它不是对手提交量，也不是对手的动作标签。双方都可以根据已经发生的市场结果调整行为，但不存在对本步对手动作的先知信息。

环境内部当然可以看到双方订单、共同队列、事件带和成交结果；这是撮合器执行任务所需的信息，不等于这些信息全部暴露给 Agent。

## 6. 状态表示与离散化规则

Q-learning 需要把连续市场变量转换为有限个离散状态。本模型采用 schedule_aware_limit_order_v2 编码。每个状态由 9 个整数特征组成：

    (时间阶段, 执行进度档, 价格偏离档, 对手成交档,
     本方报价档, 本方订单大小档, 队列档, 订单年龄档, 最后一步标记)

各特征精确定义如下。

| 特征 | 编码规则 | 取值范围 |
|---|---|---:|
| 时间阶段 | 当前步 t 除以 10 向下取整，并封顶为 5 | 0–5 |
| 执行进度 | 计算 pace = remaining / (base_slice × max(horizon − t, 1))；pace < 0.95 为 0；0.95 至小于 1.10 为 1；1.10 至小于 1.40 为 2；至少 1.40 为 3 | 0–3 |
| 价格偏离 | 计算 deviation = (mid / initial_mid − 1) × 10,000 bp；低于 −2 bp 为 0；−2 bp 至低于 +2 bp 为 1；至少 +2 bp 为 2 | 0–2 |
| 对手上期成交 | opponent_previous_qty / base_slice 小于 1 为 0；至少 1 为 1 | 0–1 |
| 本方报价档 | 无活动订单为 0；相对 mid 的偏离不高于 −2.5 bp 为 1；不高于 −1.5 bp 为 2；低于 0 bp 为 3；不低于 0 bp 为 4 | 0–4 |
| 本方订单大小 | 活动订单余量大于一个基准份额为 1，否则为 0 | 0–1 |
| 队列前方量 | queue_ahead / base_slice 至少为 1 为 1，否则为 0 | 0–1 |
| 订单年龄 | 活动订单年龄至少 2 步为 1，否则为 0 | 0–1 |
| 最后一步 | 当前 t 等于 horizon − 1 时为 1，否则为 0 | 0–1 |

理论上的组合数量是 6 × 4 × 3 × 2 × 5 × 2 × 2 × 2 × 2 = 11,520 个，但很多组合在实际运行中不会出现；Q 表只为访问到的状态保留记录，所以它是稀疏表。

当本方没有活动子单时，报价档、订单大小、队列和年龄统一编码为无订单状态。该表示同时描述交易计划是否落后、市场价格处于初始价上方还是下方、对手是否在上一时间步有较大实际成交，以及自己的限价单目前面临怎样的队列和等待时间。

状态表示的边界也需要说明：对手信息仅包含上一时间步实际成交量的二档编码，模型没有使用对手订单簿、对手 Q 值或对手意图；波动率字段传给 Observation，但不进入本版本的 9 维状态键。

## 7. 动作集合和限价单含义

每家机构的 TWAP 基准份额为：

$$
q_{\text{base}} = 100{,}000 / 60 \approx 1{,}666.67\text{ 股}.
$$

动作集合为五项。动作编号在代码中从 0 开始：

| 动作编号 | 数量系数 | 目标提交数量 | 订单类型和含义 |
|---:|---:|---:|---|
| 0 | 0 | 0 | 保留当前活动报价；如果没有活动订单，则本步等待 |
| 1 | 0.5 | 约 833.33 股 | 报深档被动买单，限价为最佳买价下方 1 个价位 |
| 2 | 1.0 | 约 1,666.67 股 | 在当前最佳买价挂被动限价单 |
| 3 | 1.5 | 2,500 股 | 报价进入价差内一个价位，尝试提高排队优先级 |
| 4 | 2.0 | 约 3,333.33 股 | 报可成交限价 IOC，最高限价为最佳卖价上方 1 个价位 |

实际新单数量还要取本方母单剩余量与目标提交量两者中的较小值。因此即使动作目标是两份基准份额，剩余母单不足时也只提交剩余股数。

### 7.1 数字价格例子

若当前中间价为 100、半价差为 2 bp、价位为 1 bp：

- 最佳买价约为 99.98；
- 最佳卖价约为 100.02；
- 动作 1 深档限价约为 99.97；
- 动作 2 最佳买价约为 99.98；
- 动作 3 价差内限价约为 99.99；
- 动作 4 的价格上限约为 100.03。

动作 4 并非无价格限制的市价单，而是有价格上限的可成交限价 IOC。它只消耗价格不高于限价的可见卖盘；容量不足时可以部分成交，剩余量立即取消。

## 8. 合成订单簿和随机市场事件

### 8.1 参数

主模型使用以下默认订单簿参数：

| 参数 | 默认值 | 解释 |
|---|---:|---|
| tick_bps | 1.0 bp | 报价档位增量 |
| quote_ttl_steps | 4 步 | 被动挂单进入第 4 个后续步时过期；约 2 分钟 |
| passive_queue_mean_base_slices | 0.12、0.65、1.10 | 新被动单前方三个层次的平均外部队列深度，以基准份额为单位 |
| sell_market_events_per_step | 1.5 | 每个 30 秒步内卖方主动订单笔数的 Poisson 均值 |
| sell_order_mean_base_slices | 0.70 | 单笔卖方主动订单的平均数量，以基准份额为单位 |
| sell_order_log_sigma | 0.55 | 单笔卖方主动订单量的对数正态波动参数 |
| ask_depth_mean_base_slices | 0.80、0.55、0.40、0.30、0.22、0.16、0.12 | 七档合成卖盘的平均深度，以基准份额为单位；普通 IOC 通常只触达前两档，加急限价单可按报价上限触达更深档位 |
| ask_depth_log_sigma | 0.35 | 队列深度和卖盘深度的对数正态波动参数 |

### 8.2 事件带的生成

每个回合开始时，模型用本回合随机种子预生成 60 步的外生市场事件带。每步包含：

- 一个高斯外生价格冲击；
- 卖方主动订单笔数及每笔数量；
- 本步新单使用的外部买方队列深度；
- 七档可见卖盘深度；
- A、B 同价订单的随机优先次序。

卖方主动订单笔数使用均值为 1.5 的 Poisson 分布。每笔卖单数量使用对数正态分布，其参数经过均值修正，使算术均值为 0.70 个基准份额，波动参数为 0.55。七档卖盘深度与外部队列深度也用对数正态随机变量生成，目标算术均值分别由上表给出。七档深度是为了表示限价逐步加急后可访问的合成流动性，不是由真实盘口估计得到。

同一评估种子会生成同一份外生事件带，因此不同冻结策略组合可以使用配对随机数进行比较。策略自身的成交会改变永久冲击，因而价格路径仍会因策略组合不同而不同。这是市场反馈带来的内生差异，不是种子配对失效。

## 9. 子单生命周期、队列与撮合规则

### 9.1 新单进入队列

动作 1 至 3 创建被动买单。新单前方数量由以下部分组成：

1. 对应价位及更优价位的外部队列深度；
2. 已经排在它前面的本方或对手活动买单数量。

新单先后顺序使用本时间步事件带中的随机 tie_order 决定。同价订单中，较早建立或较早进入队列的订单优先；外部队列作为本方报价前的显示数量近似处理。

当前活动买单的队列前方量会随着卖方主动订单流被消耗而下降。只有卖单流先穿过队列前方数量后，剩余卖单流才可能成交到本方子单。成交量因此取决于本步可用卖单流、订单在队列中的位置和本方剩余子单量。

### 9.2 动作 0：保留或等待

若本方有活动子单，动作 0 不撤销、不改价，继续保留该单及其当前排队位置。若没有活动订单，动作 0 表示这一步不提交新订单。即使动作 0，已有订单仍可能被市场撮合，特别是卖方订单流消耗到该订单的队列时。

### 9.3 动作 1 至 3：撤旧挂新

选择动作 1 至 3 会撤销本方旧活动订单，将剩余数量记为撤单量，然后按新动作提交一个被动买单。重新报价会失去旧订单的时间优先级，并根据新的报价位置重新计算队列前方量。没有成交的报价会继续留在簿上，等待后续市场事件，最多保留约 2 分钟。

### 9.4 动作 4：可成交限价 IOC

普通动作 4 会撤销本方旧单，创建一个价格上限为卖一价上方一个价位的 IOC 限价单。处于 C 方案加急阶段时，只有落后线性进度的 Agent 会被覆盖为动作 4，并按阶段逐步抬高价格上限：达到执行窗口 70% 时上移 1 个价位、85% 时上移 3 个价位、95% 时上移 6 个价位。相应限价依次覆盖更深的合成卖盘档位；每档深度仍有限。加急阶段的订单数量至少为剩余母单除以剩余步数，若超过常规动作 4 的两倍基准份额则提交追赶量。未成交 IOC 余量即时撤销，等待下个时间步重报。

### 9.5 旧被动单因价格变化变成可成交单

每步开始时，若一个旧买单限价已经达到或高于当前最佳卖价，系统会将其标为可成交，并按订单限价尝试消耗可触达的卖盘档位。若可见档位不足，该旧单不是 IOC：未成交部分可继续保留为挂单，随后按被动订单处理。这与新提交 IOC 的即时撤销规则不同。

### 9.6 排序和部分成交

可成交限价单按限价、创建时间和随机同价优先次序排序，共同消耗其限价内可触达的七档卖盘容量。普通限价上限通常只覆盖前两档；截止加急可触达更多档位。被动订单按买价从高到低、创建时间和同价优先次序排序，共同消耗卖方主动订单流。任何一笔普通限价单均可部分成交。撮合事件区分 Maker、Taker 和截止强制成交。

### 9.7 撤单场景

未成交子单会因为以下原因离开订单簿：

- Agent 重新报价时撤销旧单；
- 被动订单达到有效期；
- IOC 订单即时撮合后的未成交余量；
- 母单已完成后清理活动子单；
- 执行窗口结束时撤销活动子单；C 模式随后对母单剩余数量执行强制收盘成交，`none` 对照模式不执行该步骤。

撤单股数与实际成交股数分开记录。撤单不减少母单；这些股数仍需在之后的时间步重新安排。C 模式截止时的强制成交会减少剩余母单，并另列强制成交股数；`none` 模式则把剩余量作为未完成母单统计。

## 10. 一个完整时间步的精确执行顺序

每回合开始时，A、B 的剩余母单均为 100,000 股，初始中间价为 100。每个时间步遵循以下顺序：

1. **读取预生成事件**：取出本步价格冲击、卖方主动订单流、队列深度、七档卖盘深度和同价排序。
2. **清理及检查旧单**：若活动订单已经达到 4 步有效期，先记撤单并删除；否则检查价格变化是否使旧买单变成可成交单。
3. **冻结交易前快照**：保存当前中间价、双方剩余母单和本步决策前的活动订单状态。
4. **分别构造观察**：A、B 都使用同一个 mid_before；各自看到自己的活动订单，并只看到对手上一步的实际成交量。
5. **双方独立选动作并应用截止保护**：训练时先用 epsilon-greedy，评估时先读冻结策略。C 模式若落后线性进度，在 70%、85%、95% 阶段将最低动作提高至 4，并把报价上限逐级上移 1、3、6 个价位；`none` 模式不覆盖动作。
6. **提交、撤单和排队**：按照本步 tie_order 处理新单插入顺序。动作 0 保持旧单或等待；其他动作会替换本方旧单并提交新报价。C 加急阶段动作 4 的数量至少覆盖剩余母单除以剩余步数。
7. **撮合可成交限价单**：普通 IOC 和因价格移动而变为可成交的旧单，按限价消耗可触达的七档卖盘，计算实际主动成交量。
8. **处理 IOC 余量与旧单余量**：新 IOC 的未成交量即时取消；旧 GTC 单的剩余量可能转回被动挂单。
9. **撮合被动订单**：本步卖方主动流先消耗队列前方数量，剩余流量再对被动单产生部分或全部成交。
10. **更新普通成交会计**：记录每笔 Maker/Taker 成交和数量。
11. **执行截止兜底**：若这是第 60 步且 C 模式仍有母单余量，计算 A、B 合并兜底量，按同一个合成冲击加价成交全部剩余数量；记录强制成交量和价格。
12. **计算费用、奖励和成本**：手续费按全部实际成交名义金额计算；逐步奖励包括普通成交和强制成交。C 模式完成后未完成量为零；`none` 模式仍可能产生未完成惩罚和机会成本。
13. **更新市场中间价**：下一步价格由本步外生冲击与 A、B 全部实际成交（含兜底成交）造成的永久冲击共同决定。
14. **形成下一状态并更新 Q 表**：终止步无下一状态价值；C 的强制成交本身是环境兜底，而不是一个 Q-learning 动作。
15. **终止记录**：第 60 步后撤销剩余活动子单，记录完成率、强制成交数量、成本分解和回合结果。

由于双方同一时间步内不互相观察对方的新动作，策略不会在当步直接响应对方刚刚报出的订单；双方的动作是在共同市场转移中相互影响，并通过下一步已实现的价格、成交和对手历史成交量反馈到未来决策。

## 11. 价格、成交价与市场冲击

### 11.1 成交价格

被动 Maker 成交按本方限价执行。主动 Taker 成交按实际消耗的卖盘档位成交：卖一价以及再高一个价位。对所有主动成交，环境再按本步总主动成交量计算暂时冲击，并将其叠加到主动成交价上。Maker 成交不叠加本模型中的暂时冲击。

手续费在成交价上按单边费率逐笔计算：

$$
\text{fee}_{i,t}
= \sum_{k \in \text{本步 Agent }i\text{ 的成交}}
q_k P_k \frac{f}{10{,}000},
$$

其中 f 是手续费 bp，q_k 是成交股数，P_k 是应用暂时冲击后的执行价。

### 11.2 暂时冲击

当步双方全部主动成交的总量为 V_t^T，暂时冲击为：

$$
I_t^{\mathrm{temp}}
= 0.35 \times 1.0 \times 0.5
  \times \frac{V_t^T}{q_{\mathrm{base}}}\text{ bp}.
$$

其中 0.35 bp 是每基准份额的冲击系数，0.5 是 30 秒步长折合的分钟数。该冲击只用于本步主动成交价，不直接改变下一步中间价。被动成交价是限价成交，不应用该暂时冲击。

### 11.3 永久冲击与外生价格变化

当步双方实际成交总量为 V_t，下一步中间价按以下公式更新：

$$
P_{t+1}
= P_t \left[
1 + \frac{\epsilon_t + I_t^{\mathrm{perm}}}{10{,}000}
\right],
$$

$$
I_t^{\mathrm{perm}}
= 0.20 \times 1.0 \times 0.5
  \times \frac{V_t}{q_{\mathrm{base}}}\text{ bp},
$$

其中 ε_t 为预生成的高斯外生冲击。永久冲击由 A、B 双方实际成交合并产生。由于 A、B 都是买入者，实际成交越多，模型中的永久冲击倾向于推高中间价。临时冲击和永久冲击都不按提交量计算。

## 12. 学习目标、奖励与成本口径

### 12.1 单步学习奖励

对 Agent i，若本步实际成交股数为 q_i,t，本步含手续费成交均价为 P_i,t^all_in，参考价为初始中间价 P_0，则逐步奖励为：

$$
r_{i,t}
= -\frac{q_{i,t}}{Q_i}
  \left(
  \frac{P_{i,t}^{\mathrm{all\_in}}}{P_0}-1
  \right)10{,}000.
$$

Q_i 是该机构母单股数。该定义把奖励与实际执行股数及含费实施缺口连接起来：买入价格和手续费越高，执行负担通常越大，奖励越低；若本步没有实际成交，则本步奖励为 0。未成交的报价本身不被当成已完成交易，也不会提前从母单中扣量。

### 12.2 终局学习奖励

在第 60 步结束后，若剩余母单占比为 u，终局中间价为 P_T，则学习更新使用的终局奖励为：

$$
r_{i,T}^{\mathrm{learn}}
= r_{i,T}
  - 1{,}000u
  - u\left(\frac{P_T}{P_0}-1\right)10{,}000.
$$

`none` 对照模式下，第二项是学习用的未完成惩罚，第三项是未成交股数相对于初始参考价的终局机会成本。C 模式在第 60 步先强制成交全部余量，因此 u=0，终局未完成惩罚和剩余母单机会成本均为零；兜底成交较高的含费价格会进入实际成交奖励和成本。

1,000 bp 的固定惩罚只进入学习奖励，不并入结果表中的经济成本指标。这一区分避免把人为训练惩罚误报成实际交易成本。

### 12.3 报告的实施成本

每方报告的总成本以完整母单初始名义金额为分母：

$$
C_i^{\mathrm{bps}}
=
\frac{
  \text{实际成交现金支出}
  - \text{实际成交股数}\times P_0
}{
  Q_i P_0
}10{,}000
+
\frac{\text{手续费现金}}{Q_i P_0}10{,}000
+
\frac{U_i(P_T-P_0)}{Q_iP_0}10{,}000,
$$

其中 U_i 是终局未成交股数。C 模式下 U_i=0，实际成交现金支出包含前段自主限价成交、截止加急成交和收盘强制成交；因此强制成交不会被隐藏在未完成机会成本中。`none` 对照模式可能有 U_i>0，成本仍由以下三项组成：

1. 实际成交部分的毛实施缺口；
2. 实际成交部分手续费；
3. 未成交部分按终局价格计算的机会成本。

该口径不包含学习用的 1,000 bp 未完成惩罚。C 模式的完成率为 100% 是环境约束结果，不能作为 Q 策略优越性的证据；策略成本需要结合强制成交股数和强制成交成本贡献分析。C 与 `none` 的成本不可直接用于证明策略优劣，因为二者完成约束不同，`none` 可能通过少成交得到较低表面成本。

### 12.4 完成与强制成交

C 模式的硬完单分为三个层次：

1. **早期自主限价**：在落后进度前，A、B 仍由 Q-learning 在原五个动作中选择，限价单通过队列、卖方主动流和卖盘深度部分成交。
2. **临近截止加急**：系统将剩余母单与线性进度目标比较。只有落后时，达到 70%、85%、95% 时间点才把最低动作提高到可成交限价 IOC，并把限价逐级上移 1、3、6 个额外价位；加急阶段的订单数量至少提高到“剩余母单 / 剩余步数”。这是一层确定性的完单保护，会覆盖 Q 策略原始动作，日志同时保存原始动作和实际执行动作。
3. **收盘强制兜底**：第 60 步普通限价撮合后，如果仍有剩余母单，环境用统一的合成收盘市场单一次性成交余量。设 A、B 强制成交总量为 q、基准份额为 b，则兜底冲击为

   ```text
   impact_bps = tick_bps × sqrt(q / b)
                + temporary_impact_bps_per_slice × market_impact_multiplier
                  × step_minutes × (q / b)
   ```

   买入均价按当前中间价加半价差和上述冲击计算。该公式代表有限可见盘口之外的合成深层流动性，是明确的教学假设，不是实际交易所承诺。

因此 C 模式一定按时完成全部母单；必须单独报告完成约束、主动成交、强制成交数量和价格冲击。`--completion-mode none` 可用于保留旧限价单机制作为基线，但该模式不满足题目硬完单要求，不能当作主结果。

## 13. Independent Q-learning 的选择与更新

### 13.1 两张独立 Q 表

A、B 各维护一个状态—动作表 Q_i(s,a)。对于当前状态 s 和可选动作 a，Q 值表示该 Agent 对从当前状态选择该动作后未来累计折扣奖励的估计。由于奖励主要是负成本，策略在评估时选择访问过的动作中 Q 值最高者，也就是估计累计成本最低者。

### 13.2 epsilon-greedy 训练动作选择

每个训练回合有一个 epsilon 值，在该回合的 60 步中使用。epsilon 随训练回合线性从 0.35 降至 0.05：

- 以 epsilon 概率从全部 5 个动作中随机探索；
- 以 1 − epsilon 的概率选择当前状态中估值最高的已尝试动作；
- 若该状态还没有任何已尝试动作，确定性回退到动作 2，即一个基准份额的最佳买价挂单；
- 估值并列时使用 Agent 自己的随机数流打破平局。

C 模式下 Q 表先给出原始动作，随后由截止保护按执行进度生成实际动作和报价上移量；训练和冻结评估采用同一规则。此动作覆盖不保证普通限价单成交，最终 100% 完成由第 60 步的收盘强制成交兜底保证。`none` 模式不启用截止动作覆盖和终端兜底，可用于对照早期无硬完单机制。

### 13.3 TD 更新

对每个 Agent，非终止步的标准 Q-learning 更新为：

$$
Q_i(s_t,a_t)
\leftarrow Q_i(s_t,a_t)
+\alpha\left[
r_{i,t}+\gamma
\max_{a' \in \mathcal{A}_{\mathrm{tried}}(s_{t+1})}
Q_i(s_{t+1},a')
-Q_i(s_t,a_t)
\right],
$$

其中学习率 α=0.15，折扣因子 γ=0.98。若下一状态没有任何被尝试的动作，未来价值取 0。终止步没有下一状态，因此目标值只使用终止奖励，不自举下一状态价值。

下一状态最大化只在已有访问记录的动作中进行。这样可避免所有 Q 值为负成本时，未尝试动作的零初始化值虚高并错误地主导贪心选择。每步无论成交与否，都会记录状态、所选动作和相应的更新。

### 13.4 为什么双边同时学习具有非平稳性

一次训练回合中，A 和 B 的 Q 表都会不断更新。A 在某一时点看到的市场行为不仅由外生事件决定，也受 B 当前学习策略影响；随着 B 的动作分布变化，A 的有效环境也会变化。B 同理。因此 Independent Q-learning 在双边自博弈中面临非平稳环境，单条训练曲线波动或回报短期改善并不足以证明收敛。

## 14. 训练检查点、交叉对局与最佳反应分析

### 14.1 默认训练规模

主入口默认参数为：

- 5 个独立训练种子；
- 每个训练种子 500 个训练回合；
- 每 100 回合保存一次检查点；
- 额外保存第 0 回合未训练策略；
- 每个检查点组合、每个评估场景使用 30 个配对随机种子；
- 正常波动训练，正常波动与两倍波动冻结评估；
- 默认单边手续费 30 bp。

由此每个训练运行有 6 个检查点：0、100、200、300、400、500。交叉评估包括：

$$
5\text{ 个训练运行}
\times 6\text{ 个 A 检查点}
\times 6\text{ 个 B 检查点}
\times 2\text{ 个场景}
\times 30\text{ 个配对种子}
= 10{,}800\text{ 个回合}.
$$

### 14.2 冻结交叉对局

评估时，每个检查点策略都复制到独立对象并冻结。冻结策略不会更新 Q 值、状态访问次数或动作访问次数。对每个 A 检查点和 B 检查点组合，环境使用相同的种子集合，使不同策略组合面对相同外生价格冲击、卖方订单流、队列深度和卖盘深度。

交叉表中既包含同一训练阶段的对角对局，也包含不同阶段的非对角对局，例如早期 A 对后期 B、后期 A 对中期 B。非对角结果用于观察 A 的表现是否会随着 B 的策略检查点变化，以及不同策略阶段是否形成不同互动。

### 14.3 候选集最佳反应与后悔值

固定对手一个检查点后，评估器从本训练运行保存的己方检查点中选出平均成本最低的策略，作为候选集内的最佳反应。候选集后悔值为：

$$
\operatorname{Regret}^{\mathrm{candidate}}_i
= C_i(\text{当前对角检查点},\pi_{-i})
- \min_{\pi_i\in\Pi_i^{\mathrm{saved}}}
  C_i(\pi_i,\pi_{-i}).
$$

这表示相对于已保存检查点集合 Π_i 的成本差，不代表全局最佳反应，因为候选集合有限；它也不构成纳什均衡证明。纳什均衡需要双方策略互为最佳反应，且需要更充分的策略空间和求解/验证条件。

### 14.4 评价指标

至少同时报告：

- 总成本、毛实施缺口、手续费与未完成机会成本；
- 完成率与未完成股数；
- 提交股数与实际成交股数；
- Maker/Taker 成交量；
- 撤单量及撤单原因；
- A、B 的动作分布；
- 多训练种子和多评估种子下的均值与波动；
- 检查点交叉对局结果、训练诊断与候选集后悔值。

Q 值和训练奖励是算法内部信号，不能替代实际成交成本、完成率等经济评价指标。

### 15.2 导出一条逐步同步学习轨迹

默认运行完成后，可以从某个保存的检查点生成一条独立轨迹：

    python .\export_self_play_trace.py --checkpoint 500 --scenario normal --seed 20261103

若使用非默认输出目录，应通过 checkpoint-file 参数指向该目录中的 checkpoint_qtables_run1.json。轨迹文件记录每个时间步 A、B 各一行，通常包括：

- 决策前状态键、剩余母单和对手上一步成交量；
- 决策前中间价、Q 策略原始动作与截止保护后的动作、加急阶段、订单类型、限价和提交量；
- 旧单替换、过期、IOC 未成交量和截止撤单量；
- 队列前方数量、订单年龄、卖方主动流及卖盘深度；
- 实际成交量、Maker/Taker 成交、强制成交量及其价格、成交价和手续费；
- 暂时冲击、外生冲击、永久冲击和下一步中间价；
- 学习奖励、γ、TD 目标、Q 更新前后值和下一状态键。

这条样例的用途是解释一次输入—判断—动作—撮合—反馈—更新的闭环；它不替代交叉评估统计，也不应当被混进汇总样本。

## 16. 如何阅读结果与常见误读

### 16.1 成本必须与完成率共同看

C 模式报告成本使用完整母单名义金额作为分母，强制成交按实际兜底价和手续费纳入实际成交现金。完成率 100% 来自硬完单机制，不能作为策略优势证据。比较 C 模式下策略表现时，应同时报告总成本、前段自主成交量、截止加急成交量、收盘强制成交股数及其成本贡献。`none` 对照可能以低完成率换取较低表面成本，其结果不能与 C 模式直接排序。

### 16.2 同一外生随机种子不意味着价格路径完全相同

配对种子让策略组合共享外生冲击和事件带。不同策略提交、成交数量不同，永久冲击不同，因此从第二步起的中间价路径可以不同。这种内生差异是待研究的策略影响渠道。

### 16.3 成本为负不等于交易免费或必然执行好

若窗口价格下跌，实际成交均价可能低于初始参考价，实施成本在当前口径下仍可能为负。C 模式虽然保证完成，但负成本不代表真实市场能无条件按模型兜底价格成交。

### 16.4 双方都买入，不是零和博弈

A、B 的目标方向相同，都是买入自己的母单，并非一方盈利必然对应另一方亏损。双方通过有限卖盘、队列、共享外生市场与永久价格冲击产生策略互动。宜称为竞争性交易环境中的双智能体策略互动，不宜简单描述为零和博弈。

### 16.5 检查点优势不是全局最优或均衡

候选最佳反应只在保存的有限检查点中搜索。即使后悔值为零，也只能说明本检查点在当前候选策略集合和当前模拟环境中没有找到更低成本的已保存回应，不能声称找到了全局最优策略或纳什均衡。

## 17. 假设、限制及适用范围

1. **合成而非真实市场**：外生价格冲击、队列、订单流、卖盘深度和价格冲击参数没有通过真实逐笔行情校准。
2. **订单簿简化**：环境只用有限档位和汇总队列近似盘口，没有重建完整交易所事件流、隐藏流动性、撤单重排、撮合延迟、优先级细则或跨交易场所流动性。
3. **单资产、单方向**：仅研究两家机构买入同一资产，不涉及卖出、跨资产组合、融资约束或投资组合风险。
4. **共同目标但存在互动**：A、B 面对相同任务类型，策略影响来自竞争队列、有限显示卖盘和共同价格反馈，不代表现实机构目标结构的全部复杂性。
5. **状态聚合有信息损失**：连续变量被分箱，当前状态不直接包括整个盘口、波动率档、全部对手行为历史或宏观信息。
6. **表格方法覆盖有限**：状态—动作组合较多，训练预算有限时许多状态可能访问不足；训练曲线有改善不等于策略已收敛。
7. **训练环境和评估环境不同**：默认只在正常波动训练，再在两倍波动冻结评估，这是指定压力测试，不等于对真实市场的稳健性证明。
8. **收盘兜底是假设**：C 模式为保证课堂完单要求，在合成深层流动性上按冲击加价强制完成。真实市场可能没有足够流动性，实际价格冲击可能更高；应对终端冲击系数做敏感性分析，并把强制成交比例作为关键结果。
9. **参数经济含义需统一**：手续费、时间步、冲击缩放、订单量和价格单位必须一起说明。不同环境版本的结果不能只因都使用 Q-learning 就直接并表。
10. **不构成真实交易建议**：结果只描述该教学模拟器下的实验表现，不构成实盘可执行策略或收益预测。

## 18. 便于在其他材料中引用的机制综述

本研究构建一个收盘前限价单交易执行模拟环境，模拟机构 A、B 分别在 30 分钟内买入 100,000 股。执行窗口划分为 60 个 30 秒时间步；两家机构各自使用独立的表格型 Q-learning 策略，并根据共同交易前中间价、自身母单进度和挂单状态、对手上一时间步成交量同步选择动作。早期由 Agent 自主提交被动限价单；若落后线性进度，系统在执行窗口 70%、85%、95% 时点将最低动作提高到可成交限价 IOC，并分别把价格上限上移 1、3、6 个价位；加急阶段将子单量至少提高到剩余母单除以剩余步数。限价单按合成队列、七档卖盘和卖方主动流部分成交；第 60 步之后若仍有剩余母单，环境按可审计的深层流动性冲击公式强制成交。C 模式因此满足按时完单约束，但完成率 100% 是环境兜底保证，不是 Q-learning 单独学得的策略优势。强制成交数量和成本贡献单独报告，兜底价格仍是教学模拟假设，不代表真实市场保证。训练阶段 A、B 同步 epsilon-greedy 学习，评估阶段冻结检查点并进行配对交叉对局。研究关注双边策略互动、学习稳定性、成本与强制成交依赖，不预设某个策略更优或达到均衡，也不将合成模拟结果外推为实盘效果。
