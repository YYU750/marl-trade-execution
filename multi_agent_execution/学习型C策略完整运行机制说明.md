# 学习型 C 策略完整运行机制说明

## 1. 文档范围与当前版本

本文说明当前主模型默认使用的「学习型 C：可变报价、可变追赶量」版本，按一次仿真从输入到训练更新的顺序解释 A、B 两个执行机构如何观察市场、作出决策、进入订单簿、产生成交和价格反馈，以及强化学习如何据此更新策略。

本文描述的是代码中已经实现的模拟机制，不把研究设想写成已证实结论。主要实现文件为：

- **run_advanced_self_play.py**：一轮交易、奖励、训练、检查点保存和评估。
- **schedule_aware_q.py**：普通执行 Q 头和学习型 C-Q 决策头。
- **limit_order_book.py**：合成订单簿、限价单撮合、排队和终端兜底价格。
- **run_standard_benchmark.py**：共享参数、状态结构和普通 Q-learning 基类。
- **compare_learned_c_dynamic_twap.py**：学习型 C 与动态规则、固定 TWAP 的配对比较。

当前版本的关键变化是：当 Agent 发现执行进度落后时，C-Q 头能同时决定是否加急、IOC 限价上移多少，以及在普通子单上额外提交多少追赶量。它不按固定时间点自动执行，也不保证盘中一定成交。

## 2. 模型目标、主体与时间单位

模型模拟两家机构 A 和 B 同时买入同一类资产。每家机构有一个数量为 Q 的母单，需要在有限时间窗内执行。当前主实验参数为：

| 项目 | 当前设置 | 解释 |
|---|---:|---|
| 单家母单 Q | 100,000 股 | A、B 各自的目标买入量 |
| 执行窗口 | 30 分钟 | 一个完整仿真回合 |
| 时间步 H | 60 步 | 每步 30 秒 |
| 基准切片 b = Q/H | 约 1,666.67 股 | TWAP 均匀计划下每步的目标量 |
| 初始中间价 | 100 | 用于计算价格偏离和实施缺口 |
| 半价差 | 2 bp | 模拟最佳买价和最佳卖价相对中间价的距离 |
| 最小价位 | 1 bp | 报价档位的基础单位 |
| 单边手续费 | 30 bp，即 0.3% | 按实际成交名义金额收费 |
| 每分钟波动率 | 2.5 bp | 30 秒步长的标准差按时间平方根缩放 |
| 压力场景 | 正常波动的 2 倍 | 评估时的高波动设置 |
| 被动限价有效期 | 4 步，即 2 分钟 | 未到期、未成交或未被替换的挂单可继续排队 |

以初始价格 100、买入 100,000 股为例，单家母单的初始名义金额为 10,000,000；若全部成交，30 bp 单边费率对应的手续费约为 30,000。bp 是万分之一；成本越低越好。

每个回合的时间索引在程序中从 t=0 到 t=59。t=0 是第一个 30 秒决策点，H=60。文档中提到的第 42、51、57 步是按人类习惯从 1 开始计数的分析参照点，约对应 20 分 30 秒、25 分钟和 28 分钟。它们不是 C-Q 的硬触发点。

## 3. 一句话理解系统结构

每个交易步里，普通 Q 头主要决定「提交哪类订单以及基础子单量」；当进度落后时，独立的 C-Q 头决定「要不要把这一步升级为 IOC、提高多少报价、额外追赶多少缺口」。订单进入共享合成订单簿后，环境根据可见深度、队列、对手订单和随机订单流计算实际成交。成交量、手续费、价格冲击和进度落后共同形成学习奖励。两边 Agent 在同一市场状态中同步行动，然后分别更新各自的 Q 表。

终端兜底是独立于 Agent 的环境保障：若启用自主加兜底模式，第 60 步普通撮合后仍有余量，环境会用单独建模的收盘兜底价格完成余量。兜底成交不算 Agent 盘中自主成交，并且单独统计。

## 4. 一轮交易每一步如何运行

### 第 1 步：准备共同的外生市场事件

回合开始时，环境根据随机种子预生成 60 步的市场事件带。每一步包含：

- 外生价格冲击，按设定波动率抽样；
- 卖方主动订单数量，事件数服从均值 1.5 的泊松分布；
- 每笔卖方主动订单的数量，按基准切片缩放的对数正态分布抽样，均值约为 0.70 个基准切片；
- 被动买单前方的外部队列深度；
- 七档合成卖盘深度，均为有限数量；
- A、B 在同价同时间情况下的随机先后顺序。

当前七档卖盘的平均深度依次为 0.80、0.55、0.40、0.30、0.22、0.16、0.12 个基准切片；单步抽样的对数正态波动参数为 0.35。被动买单前方的三档外部队列深度均值依次为 0.12、0.65、1.10 个基准切片，向更优价位的订单会排在更深价位订单前。它们是可复现的教学模拟参数，不是从某只真实股票估计出来的真实盘口分布。

配对评估会让被比较策略使用同一组外生事件、初始盘口和撮合随机顺序。策略造成的成交量和价格路径不同属于模型内生反馈，不能要求不同策略最终生成完全一样的价格路径。

### 第 2 步：更新旧订单并生成观察

进入 t 步时，环境先检查 A、B 的已有挂单：

1. 挂单达到 4 步有效期后撤销；
2. 若价格变化使原限价变成可成交价，订单会转成可成交限价处理；
3. 记录当前中间价、各自剩余母单、上一步对手成交量，以及自己仍然有效的子单、排队量和挂单年龄。

A、B 的观察都取自本步交易前的同一个市场快照。A 不会提前看到 B 本步准备提交的动作；B 也不会提前看到 A 本步动作。双方可以通过过去的对手成交量、共享的盘口深度和之后发生的共同价格冲击间接感知竞争影响。

每个 Agent 主要观察自身状态：当前时间、剩余数量、当前价格相对初始价的偏离、上一步对手实际成交量、自己的活动挂单数量、自己的挂单价格档、排队量和挂单年龄。Agent 不直接观察未来的外生价格冲击或未来卖方订单流。

### 第 3 步：普通执行 Q 头提出基础动作

A、B 各自调用自己的普通执行 Q 表，得到一个基础动作。两边 Q 表独立维护，不共享学习参数。普通动作集合为五档：

| 动作编号 | 基础子单量 | 订单含义 |
|---:|---:|---|
| 0 | 0 | 本步不新提交订单；已有有效挂单可以继续留在队列里 |
| 1 | 0.5 b | 在较深的被动买价挂限价单 |
| 2 | 1.0 b | 在最佳买价挂被动限价单 |
| 3 | 1.5 b | 在买卖价差内提高报价的限价单 |
| 4 | 2.0 b | 提交基准可成交限价 IOC，限价为卖一价上方 1 个 tick |

其中 b = Q/H。子单量会受剩余母单约束：基础数量不超过当前剩余数量。动作 0 不是撤单指令；当已有挂单时，选择动作 0 表示先不替换该挂单，让它继续等待成交、到期或被其他机制处理。

普通 Q 头的状态采用离散分箱，包含九类信息：

| 状态部分 | 程序表达的含义 |
|---|---|
| 时间阶段 | 每 10 步一个阶段，合计 6 个阶段 |
| 进度比例 | 剩余母单 / 剩余时间均匀计划量；<0.95、[0.95,1.10)、[1.10,1.40)、≥1.40，四档 |
| 价格偏离 | 中间价相对初始价低于 −2 bp、介于 −2 至 +2 bp、或高于 +2 bp |
| 对手上一期成交 | 对手上一步成交量是否达到一个基准切片 |
| 自己挂单价格 | 相对中间价偏移不高于 −2.5 bp、(−2.5,−1.5] bp、(−1.5,0) bp、达到或高于 0 bp，分别标为深档、最佳买价附近、价差内、可成交；无挂单单独一档 |
| 自己挂单大小 | 当前挂单量是否超过一个基准切片 |
| 自己队列 | 前方排队量是否达到一个基准切片 |
| 自己挂单年龄 | 挂单年龄是否达到 2 步 |
| 最后一步标记 | 当前是否为执行期限的最后一步 |

这不是连续状态控制器，而是将相似场景归入同一个离散状态的表格型 Q-learning。分箱能减少 Q 表规模，但会丢失连续数值细节。另外，Observation 中虽然带有波动率字段，当前普通 Q 和 C-Q 的状态编码都没有使用该字段；高波动评估检验的是策略面对更大随机冲击时的泛化表现，而不是一个显式读取波动率标签后切换策略的 Agent。价格特征也只记录相对初始价的偏离，不直接编码短期收益趋势。

### 第 4 步：检查均匀进度并开放 C-Q 决策

对 C-Q 来说，本步决策时刻的剩余均匀计划量定义为：

$$S_t = Q \times (H-t)/H$$

其中 t 是程序的 0 起始时间索引。当前剩余母单为 R_t。当前进度缺口为：

$$D_t = \max(0, R_t-S_t)$$

如果 R_t 不高于 S_t，Agent 不落后于均匀时间表，C-Q 动作集合只有 no-C，不触发加急决策；普通 Q 头仍会照常选择基础动作。

如果 R_t 高于 S_t，说明当前剩余任务超过了剩余时间内的均匀计划量。此时 C-Q 在这个落后时点可以从 13 个动作中选择，包括 no-C。落后后每一个 30 秒步都可以重新决策，Agent 可以先等待，之后再加急，也可以连续多个步采取不同强度的行动。

程序把约 70%、85%、95% 时间位置标记为分析阶段，便于观察策略在中后段的行为。这些阶段不要求母单必须达到 70%、85%、95% 的成交进度，也不自动执行某个动作。真正的加急资格由 R_t 与 S_t 的关系决定，具体动作由 C-Q 决策。

### 第 5 步：C-Q 联合选择报价档和追赶比例

C-Q 是每个机构自己维护的一张独立 Q 表，和普通执行 Q 表分开。它的离散状态包含：

| 状态部分 | 分箱方式 |
|---|---|
| 精确时间 t | 0 至 59 的当前步索引 |
| 进度比例 | R_t / S_t，按 <1.05、[1.05,1.20)、[1.20,1.50)、[1.50,2.00)、≥2.00 分为五档 |
| 价格偏离 | 低于 −2 bp、−2 至 +2 bp、高于 +2 bp |
| 自己的挂单情形 | 无挂单；较新且队列较短；其他有效挂单 |
| 对手上一步成交量 | 是否达到一个基准切片 |

当 Agent 落后时，C-Q 的 13 个行动如下：

| 行动类型 | C 加急报价 | 在动作下限后的基础 IOC 量上额外增加当前缺口的比例 |
|---|---:|---:|
| no-C | 不覆盖普通 Q 动作 | 0% |
| 轻度加急 | IOC 限价比基准 IOC 再提高 1 tick | 0%、25%、50% 或 100% |
| 中度加急 | IOC 限价比基准 IOC 再提高 3 ticks | 0%、25%、50% 或 100% |
| 高度加急 | IOC 限价比基准 IOC 再提高 6 ticks | 0%、25%、50% 或 100% |

因此行动组合为 1 个 no-C，加上 3 个报价档 × 4 个追赶比例，共 13 个选项。报价强度和追赶数量由同一个 C-Q 状态下的组合行动决定，不是先用固定规则选一个报价，再由固定公式生成数量。

这里的追赶比例乘的是当前进度缺口 D_t，而不是母单总量，也不是 TWAP 切片：

$$\Delta q_t = f \times D_t, \quad f \in \{0, 0.25, 0.50, 1.00\}$$

C 叠加后的提交量为：

$$q_t^{submit}=\min(R_t, q_t^{base}+\Delta q_t)$$

其中 q_t^base 是 C 动作下限应用后的基础子单量：若 C 选择加急行动，则 q_t^base=min(R_t, 2b)；若选择 no-C，则不应用这条追赶量公式。R_t 是当前尚未成交的母单数量。提交量最多不超过剩余母单，所以不会由这个公式提交超过母单余量的买单。

选择任一非 no-C 的加急行动时，C 会把执行动作下限提升到普通动作 4，也就是可成交限价 IOC。由于普通动作 4 的基础数量倍率为 2.0，C 生效时的 IOC 基础提交量是 min(R_t, 2b)，再叠加下述 C-Q 选出的追赶量。普通 Q 头在本步提出的被动动作或较小动作会被这个动作下限覆盖。no-C 则不提升动作下限、不增加数量，普通 Q 原提议动作原样执行。

### 第 6 步：将 C 报价换算为限价

买方最佳卖价为 mid × (1 + 半价差 bp / 10,000)，一个 tick 等于 mid × 1 bp / 10,000。基准 IOC 的限价是最佳卖价上方 1 个 tick。C 选出的 1、3、6 tick 是在这个基准 IOC 限价之上额外增加的档数：

$$P_t^{limit}=P_t^{best\ ask}+(1+k)\times tick$$

其中 k 为 C 选择的加急档 1、3 或 6。因此：

- C +1 的 IOC 最高可接受价为最佳卖价上方 2 个 tick；
- C +3 的 IOC 最高可接受价为最佳卖价上方 4 个 tick；
- C +6 的 IOC 最高可接受价为最佳卖价上方 7 个 tick。

限价单只会成交价格不高于 Agent 自己限价的可见卖盘。限价提高扩大了可触达的卖盘档位，但不会凭空增加流动性，也不会保证全部提交量都成交。

### 第 7 步：订单入簿、排队和撮合

若 Agent 提交新订单且自己已有挂单，旧挂单先被撤销或替换；新被动限价单根据价格档和已有订单估计前方队列量。订单簿每家机构只追踪一个当前活动子单。

撮合分为两类：

1. **可成交限价 IOC（taker）**：按价格和优先顺序消耗七档合成卖盘深度；只要卖盘档位价格不高于订单限价就可能成交。允许部分成交，未成交余量立即取消。
2. **被动限价单（maker）**：共享的卖方主动订单流依价格优先穿过买单前方队列；只有流量消耗掉队列后才轮到自己的订单成交。未成交余量继续排队，但最多存续 4 个时间步。

同一时段 A、B 的可成交单竞争共同的可见卖盘。被动单竞争共同的卖方主动订单流；同价时由该步预生成的随机先后顺序决定。撮合后的实际成交股数才会减少母单剩余量。提交了多少股并不等于成交多少股。

### 第 8 步：市场反馈与状态转移

本步 taker 成交会承担临时价格冲击，按两家机构本步积极成交量计算：

$$I_t^{temp}=0.35\times m\times 0.5\times\frac{V_t^{taker}}{b}$$

其中 m 为市场冲击倍率，0.5 是 30 秒换算成分钟的步长，b 为基准切片。taker 成交价在订单簿报价基础上再计入该临时冲击。

成交后的中间价变化包括本步外生随机冲击和双方实际成交带来的永久冲击：

$$I_t^{perm}=0.20\times m\times 0.5\times\frac{V_t^{total}}{b}$$

$$mid_{t+1}=mid_t\times\left(1+\frac{shock_t+I_t^{perm}}{10,000}\right)$$

下一步中，Agent 能观察到新的中间价、自己的剩余订单和对手上一期的实际成交量。A、B 的当前行动会通过流动性竞争、临时冲击、永久冲击和剩余进度共同影响对方下一步看到的环境。这就是双边学习环境中的策略互动来源。

### 第 9 步：计算每步的经济成本与学习奖励

对每家机构，单步成交的平均执行价格含手续费。若本步有成交，单位成交实施缺口为：

$$IS_t=\left(\frac{平均成交价+手续费}{初始中间价}-1\right)\times 10,000$$

若本步成交 q_t^fill 股，经济执行奖励为：

$$r_t^{exec}=-\frac{q_t^{fill}}{Q}\times IS_t$$

r_t^exec 是反映成交成本的负向奖励：买价或手续费越高，奖励越负；若价格低于参考价，成交成本项也可能为正。若本步没有成交，单步实际成交成本奖励为 0，但 Agent 仍可能因进度落后受到时间表惩罚。

非终局步骤还计算进度惩罚。当前步撮合结束后，剩余均匀计划量为 b × (H-t-1)：

$$P_t^{schedule}=10\times\frac{\max(0,R_{t+1}-b(H-t-1))}{Q}$$

终局时，对送入兜底的股数计入强化学习惩罚：

$$P^{terminal}=1000\times\frac{q^{forced}}{Q}$$

自主模式下的实际学习奖励为：

$$r_t^{learn}=r_t^{exec}-P_t^{schedule}-P_t^{terminal}-P_t^{opportunity}$$

在启用兜底的当前实验中，兜底会把母单余量实际买完，因此完成后的剩余量是 0；兜底量仍受到终局惩罚，并且其真实价格、冲击和手续费已经计入经济成本。若关闭兜底且留下未完成数量，机会成本按终局中间价和初始价的差异计算。

**学习惩罚和报告中的经济成本不是同一指标。**进度惩罚、终局残余惩罚用于改变 Agent 学到的行为；对外报告的实施成本由实际成交价格、手续费和未完成机会成本构成，不把这些训练惩罚重复当作市场费用。

### 第 10 步：同步更新普通 Q 表和 C-Q 表

训练模式下，A、B 必须先同时完成本步决策和共享市场撮合，再计算同一市场转移结果，最后分别更新自己的表。A 不会先用更新后的策略影响 B 在本步的决定；B 也一样。

普通 Q 头的更新形式为：

$$Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha[r_t^{learn}+\gamma\max_{a'\in tried(s_{t+1})}Q(s_{t+1},a')-Q(s_t,a_t)]$$

C-Q 头用自己的状态、行动集合和 Q 表执行同类更新。当前参数为学习率 α=0.15、折扣因子 γ=0.98。终局没有下一状态，不再自举未来 Q 值。程序在下一状态自举时只考虑已经尝试过的行动，避免未尝试行动的初始零值在全是负回报时被误选为最好行动。

普通 Q 表按本步最终执行的普通动作索引更新。如果 C 把普通 Q 原先提议的被动动作提升为 IOC，普通 Q 头记录的是实际执行的 IOC 动作；C-Q 表则记录 C 头实际选择的 no-C 或某个报价—追赶量组合。两个头收到同一个最终学习奖励。这使两个决策层共同优化总体执行结果，同时也让收益归因无法完全拆分为「普通动作贡献」和「加急动作贡献」。

## 5. 训练与冻结评估

训练时每个独立训练运行从空 Q 表开始，A、B 同时学习；每个 Agent 内部普通 Q 头和 C-Q 头分别维护 Q 值和行动访问次数。ε-greedy 探索率从 0.35 线性下降到 0.05：以 ε 概率从允许行动中随机探索，否则在已尝试行动中选择当前 Q 值最高者；并列时用带种子的随机数打破平局。普通 Q 头使用 5 个基础动作，C-Q 在落后时使用 13 个组合动作。

当前已执行的一轮主训练设置为：5 个独立训练种子，每个种子训练 1,000 回合；每回合 60 步。训练在正常波动环境中进行。将训练结束后的 A、B 策略冻结后，在正常波动和 2 倍波动下评估；每个训练种子、场景使用 30 个评估随机种子。策略冻结时不再更新 Q 表，也不执行训练探索；若普通 Q 状态没有访问过已尝试行动，回退到基准切片动作；若 C 状态从未见过，则回退 no-C。

同一种训练种子的最终检查点相互对局，是双边学习的自博弈评估。学习型 C 与固定动态规则、固定 TWAP 对照，是另一类实验；两类实验的对手行为不同，结果不能混为一组样本。

## 6. 当前订单簿完单机制和 Agent 职责边界

当前主结果采用自主决策加终端兜底模式：第 1 至 60 步的订单类型、数量、报价和 C 加急决策仍由 Agent 负责；第 60 步普通撮合后，若有余量，环境才将该余量送入合成收盘兜底。

兜底价格使用明确的合成深层流动性曲线。令两家合计兜底股数为 F，兜底量以基准切片计为 n=F/b，则额外冲击约为：

$$I^{backstop}=1\times\sqrt{n}+0.35\times m\times0.5\times n\quad bp$$

买入兜底价为终局中间价加半价差与上述冲击。A、B 的兜底余量使用同一个受合计余量影响的终端价格，之后按实际兜底成交量收手续费。该兜底是仿真规则，不是实盘订单、真实收盘价或真实交易所保证。

因此需要分开报告：

- 总完成率：包含兜底后的母单完成率；
- 盘中自主成交量：由 Agent 订单经过限价簿撮合产生；
- 兜底量：环境最后强制处理的余量；
- 成本：包括普通成交和兜底成交的价格、手续费及适用的机会成本；
- C 追赶提交量：C 相对普通基础子单额外提交的量，不等于其实际成交量。

不能因为总完成率为 100% 就说 Agent 自己已经盘中买完全部订单。学习型 C 只能努力减少终局余量，不能控制未来随机卖盘，也不能让限价范围外或不存在的卖盘成交。

## 7. 一次 C 决策的数值示例

假设刚到第 42 个 1 起始决策步，程序索引 t=41；剩余 19 个可执行步骤。母单 Q=100,000，基准切片 b≈1,666.67，当前剩余 R_t=40,000 股。

当前剩余均匀计划量约为：

$$S_t=100,000\times19/60\approx31,666.67$$

所以当前进度缺口 D_t 约为 8,333.33 股。假设普通 Q 头原先提议一个被动动作，基础量为 1.0 个基准切片；C-Q 选择「IOC +3 ticks、追赶 50%」。由于非 no-C 动作把普通动作提升到动作 4，C 生效后的 IOC 基础量为 2 个基准切片，约 3,333.33 股。

- C 加急量约为 8,333.33 × 50% = 4,166.67 股；
- 本步提交量为 3,333.33 + 4,166.67 = 7,500 股，且不超过 40,000 股剩余母单；
- 动作升级为 IOC；
- 报价限价为最佳卖价上方 4 个 tick；
- 订单簿只用限价内可见的卖盘撮合。若这些档位合计深度不足 7,500 股，本步只能部分成交，未成交 IOC 余量取消；在该五档的平均深度参数下，合计深度约为 2.27 个基准切片，即约 3,783 股；实际深度还会随机变化，也会受到对手消耗影响；
- 下一步根据实际成交后的剩余母单、价格、对手上一期成交和自己新挂单状态重新观察，Agent 可以再选择等待、温和加急或更强加急。

这个例子中 Agent 决定了「提交量与报价强度」，但成交量由订单簿决定。追赶量不是一次性补齐所有落后股数的强制成交指令。

## 8. 结果评价与当前实验结论

评价时至少同时观察成本、盘中自主成交量、兜底量、成交方式和跨种子波动。只观察 Q-learning 累计奖励容易误导，因为惩罚系数是训练信号；只观察总完成率也会被兜底机制掩盖。

当前 1,000 回合 × 5 个训练种子的双边同步学习最终检查点评估中，正常波动下 A、B 的平均成本约为 40.000±1.546 和 39.895±1.553 bp；两倍波动下约为 38.786±2.061 和 38.989±2.117 bp。这里的 ± 是五个训练运行平均值之间的标准差。平均兜底量分别约为：正常波动 A 1,665 股、B 2,259 股；高波动 A 2,200 股、B 3,054 股。跨训练种子的波动仍然存在；这组数据没有证明策略已收敛，也没有证明 A 稳定优于 B。

在与固定规则的配对比较中，学习型 C 在当前模拟设置下比动态规则成本低约 6.18–6.66 bp，兜底量少约 4.14 万–5.81 万股；但相对固定 TWAP，学习型 C 成本高约 0.78–1.08 bp，兜底量多约 339–6,535 股。报告和逐次数据位于：

- [双边学习自博弈结果](./outputs/advanced_self_play_learned_c_flexible_quantity_1000x5x30/findings.md)
- [与动态规则、固定 TWAP 的配对比较](./outputs/learned_c_flexible_quantity_comparison/findings.md)
- [本策略的简版机制说明](./学习型方案C机制详解.md)

这些是合成环境下的实验结果，不能直接外推到真实市场，也不能把一次模拟优势写成普遍最优。

## 10. 适用边界和阅读结论时的注意事项

1. 这是表格型、离散状态的 Independent Q-learning。策略质量依赖状态分箱、训练轮数、随机种子和对手策略。
2. 双方同时学习导致对单个 Agent 来说环境随对手策略变化而非平稳；检查点表现相近不等于达到纳什均衡。
3. 对手特征主要是上一步实际成交量的粗分箱，并不是对手完整 Q 表、意图或未来动作的显式模型。
4. C 的报价—数量行动空间是离散的，不是连续优化。当前能选的加急比例只有 0%、25%、50%、100%；报价档只有 1、3、6 tick。
5. 当前合成限价簿包括有限卖盘深度、队列、部分成交、订单有效期和随机卖盘流，但没有完整复制交易所撮合细则、隐藏流动性或真实市场订单流。
6. 完单兜底的深层流动性价格曲线是显式模拟假设。自主成交率必须从总完成率中扣除兜底股数后单独计算。
7. 30 bp 手续费对执行成本有很大影响。不同费率、波动、时间步长或盘口参数下应重新训练和配对测试，不应直接沿用旧参数结果。
8. 运行报告中的点估计和区间只针对各自的模拟设定及测试种子；它们不是实盘收益承诺，也不证明 Q-learning 总能超过 TWAP。

总体来说，当前机制让 Agent 自主选择普通执行动作，并在进度落后时自主选择加急时机、报价强度和追赶数量。订单簿决定实际成交，学习奖励把成本、进度和终局残余反馈给两张 Q 表；如果研究设置要求硬性完成，当前实验中的终端兜底负责最后的完单保证，并且与 Agent 自主表现分开统计。

## A/B 市场参与率与规模差异

A、B 是当前模型中仅有的两个显式学习型买方，但并非市场中仅有的交易参与者；模拟器还生成背景成交量代理、外部卖方订单流、队列和可见卖盘。程序新增 5%、25%、60% 三档合计计划参与率。三档均保持 A、B 各买入 100,000 股，A:B=1:1；背景成交量代理的期望按目标参与率反推。外部订单流和盘口深度相对 25% 中档按背景量线性缩放，临时/永久/终端冲击系数按背景量平方根反比调整。该背景量是独立的外生周转代理，并没有把所有第三方参与者作为独立订单逐笔生成和撮合。三档都是合成参数情景，尚未基于历史成交量和盘口数据校准。

每回合的输出记录计划参与率、背景成交量代理、A+B 普通 maker/taker 成交量、模型内普通盘口成交参与率，以及把终端兜底纳入分子的补充比例。主实现参与率按 `(A+B 普通成交量)/(A+B 普通成交量+背景成交量代理)` 计算，防止强制完单兜底掩盖 Agent 的盘中执行差异。这里的“实现”是指在模拟器内根据生成量计算出来，不等于真实市场实测。autonomous 模式含兜底比例会因总成交量接近计划母单而按构造接近目标档位，不是策略表现的独立证据。相同种子跨档生成相同的外生价格冲击与标准化随机创新，订单流强度、盘口深度和冲击映射按档位变化。每档策略分别训练，因此结果反映各档单独适应后的表现，不是同一冻结策略跨档泛化结果。

可以从项目目录运行 `python .\\run_participation_tier_sweep.py --episodes 500 --training-runs 5 --eval-seeds 30 --checkpoint-interval 100`，自动运行三档并生成 `outputs/participation_tier_sweep/tier_comparison.md` 和 CSV。旧的无参与率分层环境仍可通过 `--participation-tier legacy` 复现。当前尚未实现 A:B=3:1、9:1 的规模差异，因此不能仅用当前三档结果讨论大机构与小机构的相互影响。详细定义、映射参数和结论边界见[AB市场参与率分层与实验设计](./AB市场参与率分层与实验设计.md)。
